## 승인 범위와 업무 근거

2026-11-18 사용자가 현황 분석과 개선 계획을 확인한 뒤 구현·검증·문서 작성 및 대체 Python 5개 정리를 승인했다. 구현 완료 후 폴더명 변경도 별도로 승인받아 `survey_response_classification`으로 변경했다. 작업 시작 시 `master / 343547d`였고 Git 변경 사항은 없었다.

업무 설명은 [수요조사 업무 기록](../reference/records/gonggam-data/work/public-data-demand-survey.md)의 기존 사용자 확인 내용에 근거한다. 대부분 담당 기관의 주관식 응답에 대표 코드의 처리 방식을 적용했고, 응답 기반 분류체계 설계 → LangChain 1차 분류 → 사람 재검토 → 집계·대표 답변 선정 → 보고서 작성으로 연결했다. 이를 모든 기관·연도의 동일한 범주·모델 설정이나 현재 코드의 실제 업무 재실행으로 확대하지 않았다. 원본 설문·개별 응답·내부 보고서는 읽거나 외부로 전송하지 않았다.

## 한계와 후속 확인

- 실제 API 인증·과금·모델 응답 품질·기관 응답 분류 정확도·검토 수정률·시간 절감은 미검증이다.
- 가상 Excel의 입출력과 원본 값 보존을 확인했으며 실제 기관 설문·기존 결과 파일을 재처리하지 않았다. 기존 따옴표가 섞인 분류 결과는 자동 추정 보정하지 않으므로 사람 검토 후 새 형식으로 정리해야 한다.
- 장시간·대용량 설문, 매 행 전체 Excel 저장에 따른 성능, 네트워크 드라이브·다른 운영체제·파일시스템의 하드 링크 지원은 미검증이다.
- API 응답 수신 직후 저장 전에 프로세스가 강제 종료되면 해당 행의 완료가 기록되지 않아 재개 시 다시 호출될 수 있다. 원격 요청의 정확히 한 번 실행을 보장하지 않는다.
- 강제 종료·전원 차단 때 남은 `.lock`·임시 파일은 자동 삭제하지 않는다. 관련 프로세스가 종료되었는지 확인한 뒤 운영자가 정리한다. 일반 예외와 사용자 중단의 잠금 정리는 검증했다.
- 외부 프로그램과의 동시 편집은 지원하지 않는다. 저장 직전의 해시 비교는 확인 시점의 변경을 감지하며, 비협조적 외부 쓰기와의 모든 경쟁 상황을 잠그는 기능은 아니다.
- 먼저 완료된 네 폴더의 검증 결과는 기존 기록이며 이번에 다시 실행한 것으로 표현하지 않는다. 승인된 이름 변경과 현재 경로 정리는 완료했다.
