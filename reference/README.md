# 이력 웹사이트 원자료

이 폴더는 이력서 웹사이트의 편집용 원자료입니다. 채용 담당자에게 보여줄 내용은 [이력 개요](overview.md)에서 시작하고, 세부 문안과 근거는 [커리어 문서 지도](career-document-map.md)를 통해 각 기록에서 확인합니다.

| 위치 | 웹사이트 작업에서의 용도 |
| --- | --- |
| [이력 개요](overview.md) | 소개, 경력, 대표 경험, 공개 연락처와 링크의 기준 |
| [커리어 문서 지도](career-document-map.md) | 승인된 이력 22개와 상세 기록의 위치 |
| `records/` | 각 이력의 승인 문안, 역할·성과·출처 |
| `reference/` | 내부 증빙 원본 |

공감데이터는 [전용 안내](records/gonggam-data/README.md)에서 **평가제도 → 회사·기관 이력 → 담당업무 → 특이 사례** 순서로 읽습니다. 평가 기준에 대한 조사와 본인의 실제 수행 근거는 구분합니다. [2026년 지표 연결표](records/gonggam-data/evaluation/indicators-2026.md)와 [GOAD 직접 분석 사례](records/gonggam-data/cases/kpf-goad-2025.md)를 추가했으며, 기존 이력의 승인·공개 범위는 유지합니다.

## 웹사이트 공개 기준

- 각 기록의 공개 범위에서 승인된 내용만 사용합니다. 공감데이터 Excel 기재 기관명·담당 업무·성과 수치·평가 등급은 공개 가능합니다 (2026.11.04). 대상 지표, 출처, 평가 상태를 함께 유지합니다.
- 이 폴더 전체를 정적 사이트나 다운로드 목록에 포함하지 않습니다. 내부 증빙, 문서 관리 메모, 회사 프로젝트 화면·원본 산출물은 배포 대상에서 제외합니다.
- 원문·페이지 이미지·캡처·다운로드 링크의 공개 범위는 상세 기록에서 확인합니다. 예외는 [언론진흥재단 분석](records/gonggam-data/work/analysis-policy-use.md), [품질진단](records/gonggam-data/work/data-quality-management.md), [민간활용](records/gonggam-data/work/private-data-utilization.md)에 정리했습니다.
- 개인 기여와 팀·기관 성과, 실제 구현과 계획, 코드 확인과 실행 검증을 구분합니다. 국토부 사례집은 기관 최종 확인 대기 상태로 유지합니다.
- 2026.11.13 사용자가 승인한 ACT 포트폴리오의 선별 이미지·도식·보고서 표지와 FindSeoul 상세기획서의 서비스 화면은 각 프로젝트 기록의 지정 범위에서 웹에 사용합니다. 원본 PDF 전체·내부 보고서 본문·동의서는 포함하지 않습니다. 이 최신 승인은 해당 선별 이미지에 관한 이전 비공개 표기를 대체합니다.

- 공개 프로젝트와 대표 코드는 해당 기록에서 허용한 범위로 사용합니다. 대표 파일 수는 개발 규모로 환산하지 않습니다. 공개 코드의 열람, 개별 업무 적용, 실행·성능 재현은 각각 구분합니다.
