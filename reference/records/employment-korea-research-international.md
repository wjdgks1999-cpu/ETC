# 회사 경력: 코리아리서치인터내셔널

상태: 작성 완료 (사용자 확인, 2026.11.02). 회사·협력사 명칭, 팀 구성, 수행 내용, 공개 GitHub 링크, 사업비 공개 가능. 6천만원 데이터바우처 수주 건의 사업명·참여 범위 등은 확인 필요로 남김.

- 공개용 회사명 또는 익명 표기: 코리아리서치인터내셔널 (실명 공개 가능, 사용자 확인, 2026.11.02)

- 주요 업무:
  - 데이터·AI 관련 정부 지원사업의 사업계획서 및 발표자료 작성과 제안 실무

  - 프로젝트별 라벨을 도메인별로 통합·표준화하고 학습 데이터에 적용하는 실무
  - Power BI 기반 데이터 관리·분석 대시보드 개발 및 운영
  - 외부 AI 공급기업 및 사내 실무진과의 협업, 아르바이트 인력 3명의 데이터 정제·라벨링 작업 배분·교육·검수·일정 관리 및 정산 내역 계산·상신
- 직접 책임진 업무 범위:
  - **의류산업 프로젝트**: 기업 데이터 수집·가공, 분석 방법 적용, 현황 분석과 인사이트 도출, R Shiny 앱 개발 등 핵심 데이터 분석·개발 실무를 주도했다. 초기 보조 업무에서 출발해 프로젝트의 주요 기술 업무를 맡게 되었다. 고객사의 만족은 사용자 설명에 근거하며 별도의 만족도 수치는 없다.
  - **AI 정성 데이터 플랫폼 프로젝트**: AI 기술 수요기업의 실무자로서 제안서 작성부터 참여했다. 학습 데이터 발굴·정제, 통합 라벨 체계 수립과 데이터 재적용, 아르바이트 인력 3명의 작업·교육·검수·일정·정산 실무, 애자일소다와의 협업을 주도했다. Python 업무 자동화와 데이터 수집 현황 대시보드 운영도 수행했다.
  - **국민건강보험 소셜 데이터 프로젝트**: 프로젝트 중간에 합류해 데이터 정리와 Power BI 대시보드 제작을 수행했다 (사용자 확인, 2026.11.02). 토픽·키워드 추출에도 일부 참여한 것으로 기억한다고 설명했다. 구현 내용과 남아 있는 불확실성은 [프로젝트 기록](project-nhis-social-data-dashboard.md)에 정리했다.
- 함께 일한 조직 또는 역할:
  - 입사 당시 신설 팀은 본인, 이사 1명, 팀장급 1명으로 구성된 3인 조직으로 이해했다 (사용자 설명 기준).
  - 의류산업 사업은 이사의 네트워크를 통해 수요기업과 연결되었고 데이터바우처 지원 대상으로 선정되었다. 본인은 데이터 분석·앱 개발 실무를 담당했다. 팀장급 구성원의 세부 분담은 현재 정보만으로 확정하지 않는다.
  - AI바우처 사업에서 코리아리서치인터내셔널은 수요기업, 애자일소다는 AI 기술 공급기업으로 참여했다. 본인은 수요기업 측 데이터 준비와 실무 조율을 담당했고, 공급기업은 AI 모델 개발을 담당했다.
  - AI 학습 데이터 준비 과정에서 사내 리서치 실무진·라벨링 관련 부서와 협업했다. 아르바이트 인력 3명의 작업 배분·교육·산출물 검수·일정 관리와 아르바이트비 정산 금액 계산·상신을 맡았다 (사용자 정정·추가 확인, 2026.11.02).
- 재직 중 역할 변화: 신설 팀의 신입 구성원으로 사업계획서·발표자료 작성 등 제안 지원 업무를 시작했다. 이후 의류산업 프로젝트의 데이터 분석·앱 개발을 주도하고, AI 도입 프로젝트에서는 데이터 준비와 협력사·실무진 간 조율을 맡는 방향으로 책임 범위가 확대되었다. 공식 승진·직책 변경 여부는 확인되지 않았다.

### AI 플랫폼의 진행 단계와 본인의 완료 범위

리서치 회사에서 주관식 답변에 라벨을 부여하는 작업에 많은 시간과 인력이 소요되어, 이를 자동화할 AI를 도입하고 사내 플랫폼으로 활용하는 것이 목표였다. 본인은 텍스트 클린징에 더해 프로젝트마다 다른 라벨의 통합·분리 기준을 정리하고, 표준화한 체계를 기존 데이터에 다시 적용하는 업무를 주도했다.

사용자의 기억에 따르면 전달한 데이터로 학습한 AI 모델은 목표 성능을 충족했다. 다만 평가 지표·목표값·측정값은 현재 확인되지 않았으므로 정량 성과로 확정하지 않는다. AI 모델 개발과 학습은 공급기업의 역할로 구분한다.

퇴사 시점에는 API·프런트엔드 등 플랫폼을 구현하는 과정이 진행 중이었다. 사용자는 본인에게 주어진 데이터 준비·라벨 체계 관련 역할을 완료한 후 퇴사했다고 설명했다. 전체 플랫폼의 개발·배포 완료 여부와 이후 운영 성과는 현재 정보로 확정하지 않는다.

## 공개 검토

- 공개 가능 여부: 회사명·애자일소다 명칭, 초기 3인 팀 구성, 본인의 수행 내용, 두 공개 GitHub 링크 및 사업비 공개 가능 (사용자 확인, 2026.11.02). AI 프로젝트의 5개 도메인·445개 프로젝트 선정 규모와 개인별 시간 절감 효과도 공개 가능하다. 각 프로젝트의 성과 근거와 남아 있는 불확실성은 해당 기록에 표시했다.
- 공개 전에 익명화하거나 제외할 정보: 회사 프로젝트의 화면·산출물 원본은 포트폴리오에 표시하지 않는다 (기존 원칙). 비공개 고객 데이터·응답 원문·내부 문서, 증명서의 개인 식별 정보와 문서 확인 정보는 제외한다. 의류산업 수요기업의 구체적인 명칭은 현재 기록하지 않았다.
- 사실 확인이 필요한 내용:
  - 기존 이력서의 6천만원 데이터바우처 수주 사업의 명칭, 중복 여부 및 참여 범위. 수주 사실은 사용자 확인을 마쳤으며 추가 자료가 확보되면 세부 내용을 보완한다.
  - 개별 프로젝트의 정확한 수행 기간, 평가 지표·산정 근거 및 성과 수치의 공개 범위는 각각의 프로젝트 인터뷰에서 확인
