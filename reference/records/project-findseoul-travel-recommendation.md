# FindSeoul · 서울 관광지 대화형 추천 서비스

상태: 완료 · 사용자 답변·제출 최종본 코드 대조 반영 후 문안 확인 (2026.11.06)

## 기본 정보

- 프로젝트명: FindSeoul
- 공개용 프로젝트명: FindSeoul
- 수행 기간: 2025.04 ~ 2025.06 (2026.11.13 사용자 기간 수정). 기존에 확인한 2025.04.01 착수 근거는 보존하며, 표시 기간은 월 단위로 사용합니다. 종료 일자는 만들지 않습니다.
- 팀: 경진대회 기획서상 SeoulMate. 팀 규모·소속은 미확인입니다.
- 적용 분야: 서울 자유여행객 대상 관광지 추천.
- 본인의 역할: 아이디어 기획·구체화, 데이터 선택, LLM 시스템, 웹서비스 프론트엔드·백엔드, 테스트·배포 담당.
- 관련 회사 경력 또는 학력 기록: 연결 근거 미확인.

## 문제와 목표

자유여행객이 정해진 선택지로 표현하기 어려운 여행 취향을 대화로 수집하고, 그 취향에 맞는 서울 관광지와 추천 근거를 제시하는 것이 목표였습니다 (기획서 PDF 2~4쪽).

초기 기획에는 DB 구축, 챗봇·추천, 웹 연동 및 테스트가 포함됐습니다. 추천 고도화·시간 단위 여행 플래너·모바일 앱은 후속 계획으로 기재됐습니다. 검토한 제출 코드에서는 여행 기초정보 입력, 선호 수집 대화, 관광지 추천 웹 흐름을 확인했습니다 (기획서 10·12쪽, 제출 코드).

## 본인의 책임과 주도 경험

- 서비스 아이디어를 구체화하고 활용할 데이터를 선택했습니다. 선호 수집과 추천을 위한 LLM 시스템 및 웹 프론트엔드·백엔드를 담당했습니다.
- 웹서비스 테스트와 배포를 맡아 경진대회 제출까지 진행했습니다.
- 팀원들은 데이터 정제와 상세기획서 등 관련 문서 작성을 맡았으며, 본인도 두 작업에 참여했습니다.
- 기술 선택의 구체적 이유와 작업 중 문제 해결 사례는 미확인입니다.

| 항목 | 기획서 기재 | 제출 코드에서 확인한 구현 |
| --- | --- | --- |
| 데이터 | 서울 열린데이터광장 관광 데이터, VISIT SEOUL 설명과 Google Maps 정보로 DB 구성 (5쪽) | SQLAlchemy 모델에 관광지 이름·주소·좌표·한영 설명·지도 링크 등의 필드를 정의했습니다. Pinecone에서 후보를 검색하고 결과에 관광지 상세 정보를 연결합니다. 실제 적재 건수·원천별 반영 범위는 미확인입니다. |
| 대화 | GPT 기반으로 여행 선호 수집 (6~7쪽) | GPT-4o-mini를 사용한 LangGraph 대화 흐름에서 선호 정보를 수집하고, 도구 호출에 따라 수집 완료 여부를 분기합니다. PostgreSQL 체크포인터로 대화 그래프 상태를 저장하도록 구성했습니다. |
| 추천 | 대화 분석, 관광지 검색·평가, 필요 시 재검색, 최종 추천 (6~9쪽) | o3-mini로 대화와 여행 정보를 분석해 검색 질의를 구성합니다. OpenAI text-embedding-3-small과 Pinecone으로 후보를 검색하고, 적합도 평가 후 후보가 부족하면 질의 수정·재검색을 거쳐 추천합니다. 적합도 기준은 코드 내부의 후보 선별 규칙입니다. |
| 웹 및 연동 | Python, LangChain·LangGraph, Reflex, FastAPI, Postgres, Pinecone (11·16쪽) | Python·Reflex로 홈, 여행 정보 입력, 채팅, 추천 페이지를 구성했습니다. 추천 페이지에서 LangGraph 이벤트를 비동기로 받아 추천 진행과 결과를 표시합니다. LangChain·LangGraph, PostgreSQL 체크포인트, SQLAlchemy, Pinecone 연동을 확인했습니다. 별도 FastAPI 앱의 구현은 확인하지 못했습니다. |
| 검증 | 초기 일정에 서비스 테스트 포함 (10쪽) | 사용자 설명으로 제출 전 테스트·배포를 확인했습니다. 테스트 항목·비교 기준·배포 주소와 현재 동작은 미확인입니다. |

## 채용 담당자용 요약

- 한 문장 요약 · 여행자의 취향을 대화로 파악해 서울 관광지를 추천하는 웹서비스 FindSeoul을 기획하고, LLM·웹 구현부터 테스트와 배포까지 담당했습니다.
- 상세 요약 · LangGraph로 선호 수집과 추천 흐름을 구성하고 Pinecone 벡터 검색과 LLM 평가를 연결해 후보가 부족할 때 재검색하도록 구현했습니다. Reflex 웹에서 대화와 추천 결과를 제공하고, 팀원과 데이터 정제·출품 문서를 준비해 2025년 서울 열린데이터광장 공공데이터 활용 창업 경진대회에 제출했으며 심사 결과 미선정이었습니다. [공개 GitHub 저장소](https://github.com/wjdgks1999-cpu/reco_seoul)
- 드러나는 역량 · 공공데이터 기반 서비스 기획, LLM 워크플로 구성, 웹서비스 연동 및 배포.
