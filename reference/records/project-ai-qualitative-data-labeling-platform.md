상태: 작성 완료 (사용자 확인, 2026.11.02). 수요기업 실무 주도, 아르바이트 인력 3명의 업무·교육·검수·일정·정산 실무, Python 자동화 및 개인별 시간 절감, 데이터 규모·성과 수치의 공개 범위를 반영했다. 일일 평균 약 1시간 절감은 과거 이력서와 본인 설명에 근거하며, 측정 기간·전후 집계 자료 및 AI 성능 세부 수치는 확인되지 않았다.

## 문제와 목표

- 프로젝트가 시작된 배경과 문제: 주관식 답변에 사람이 라벨을 부여하는 작업에 많은 시간과 인력이 투입되고 있었다. 코리아리서치인터내셔널은 애자일소다를 공급기업으로 두고 AI바우처 지원사업에 참여해 자동 라벨링 AI를 도입하려 했다. 기존 데이터는 직원들의 컴퓨터에 로컬 Excel 파일로 분산되어 있었고 프로젝트마다 라벨 체계가 달라 학습용 데이터로 활용하려면 수집·정제와 기준 통합이 필요했다.
- 달성하려는 목표 및 성공 기준: 리서치 답변의 토픽·감성을 자동으로 라벨링하는 AI와 내부 플랫폼을 구축한다. 본인의 담당 목표는 학습 가능한 데이터를 준비하고 도메인별 통합 라벨 체계를 적용해 공급기업에 전달하는 것이었다. 공급기업이 개발한 AI의 정확한 목표 성능값·검수 지표는 현재 확인되지 않았다.
- 주요 제약 조건: 데이터의 로컬 파일 분산, 프로젝트별로 다른 문항·코드프레임·라벨 체계, 데이터의 완결성 차이, 여러 실무진·아르바이트 인력과 함께 진행하는 데이터 정제 및 라벨 재적용 작업, 공급기업이 활용할 수 있는 구조로의 변환 필요

## 수행 방법

- 사용한 데이터의 종류 및 규모: 사내에 보관된 리서치 주관식 답변과 프로젝트별 라벨·코드프레임. 과거 포트폴리오 14쪽에는 공공, 전자, 식품, 브랜드 이미지·광고효과, 마케팅 서비스의 5개 도메인과 그 하위 445개 프로젝트를 학습 대상으로 선정했다고 기재되어 있다. 이는 선정 범위이며, 445개 프로젝트 모두의 수집·검수·학습이 완료되었다는 의미로 확대하지 않는다. 최종 전달한 유효 응답 건수는 현재 확인되지 않았다.
- 분석 방법 또는 AI 접근 방법: 학습 대상 선별, 데이터·코드프레임 정합성 검수, 도메인별 라벨 통합·분리와 기존 데이터 재라벨링. 공개 저장소에는 통합 라벨 체계 구축을 돕기 위한 텍스트 전처리·유사 문서 군집 탐색 코드가 포함되어 있다. 자동 라벨링 AI 모델의 개발은 공급기업 역할로 구분한다.
- 사용한 기술 및 도구: Python·pandas, MySQL, Power BI·Power BI Service, Power Query, DAX. 공개 전처리·탐색 코드에는 mysql.connector, PyKoSpacing, hanspell, KoNLPy의 Okt, scikit-learn의 TF-IDF·DBSCAN·t-SNE 등이 참조되어 있다. 개별 실험 방법의 실제 업무 적용 범위는 현재 자료에서 모두 확인되지는 않는다.
- 방법을 선택한 이유: 서로 다른 프로젝트의 답변과 라벨을 공통 구조로 정리해 학습에 사용할 수 있도록 하고, 데이터 준비 과정을 검수·추적할 필요가 있었다. 현황은 DB와 연결된 대시보드로 확인할 수 있게 했다.
- 결과를 검증한 방식 및 비교 기준: 공개 검수 코드에서 데이터·코드프레임의 시트 구성, 제품·문항 일치, 중복 코드, Sub-Net 값과 상위 Net 연결 등을 검토하는 로직을 확인했다. 포트폴리오 16쪽의 라벨 체계 개선 과정에는 1차 학습 결과의 precision·recall·F1·support 등을 참고하는 단계가 제시되어 있다. 실제 결과값과 최종 AI의 평가 세부 절차는 확인되지 않았다.

### 데이터 관리 대시보드

기존 이력서와 포트폴리오는 로컬 Excel 기반 관리 정보를 DB로 적재하고 Power BI로 수집·검수 현황을 관리한 과정을 설명한다. Python·Power Query로 전처리를 정의하고 DAX로 필요한 측정값을 작성했다. 대시보드는 Power BI Service에 올려 갱신 주기를 설정했으며, Python 스크립트가 있어 개인 모드 데이터 게이트웨이를 사용한 것으로 기재되어 있다.

확인 가능한 관리 내용은 프로젝트 선정·탈락, 수집 및 유효 데이터 수, 작업 완료 여부 등이다. 자료의 ‘실시간’ 표현은 주기적인 데이터 갱신에 기반한 현황 확인으로 설명한다. 공급기업이 개발한 최종 AI 플랫폼과 별도로 본인이 수행한 내부 데이터 관리 업무다.

### Python 자동화와 시간 절감의 기준

사용자는 직접 만든 Python 코드를 각 담당자가 업무에 활용하면서 자동화와 효율 향상이 있었고, 시간 절감은 개인별 기준이라고 확인했다 (2026.11.02). 과거 이력서의 ‘일일 평균 1시간 절감’은 이 확인을 반영해 개인별 일일 평균 약 1시간의 업무시간 절감으로 기록한다. 이는 기존 이력서와 본인 설명에 근거한 수치이며, 측정 기간·전후 시간 집계 자료는 확보되지 않았다.

과거 이력서는 대시보드에 의한 일일 보고 문서 대체를 설명하고, 이번 답변은 Python 코드로 각자의 담당 업무를 자동화한 기여를 보완한다. 시간 절감은 이 업무 개선 맥락에서 설명하며, Python 자동화와 대시보드 각각의 기여 시간을 분리해 산정한 수치로 제시하지 않는다.
