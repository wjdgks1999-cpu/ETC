# 프로젝트: 국민건강보험 소셜 빅데이터 분석 대시보드 개발

상태: 작성 완료 (사용자 확인, 2026.11.02). 기록된 프로젝트명·관련 명칭·분석 주제·기본 데이터 개요·수행 내용 공개 가능. 토픽·키워드 추출의 일부 참여는 본인 기억에 근거하며, 세부 작업·팀 구성·검수·배포 절차 등은 확인되지 않았다.

## 기본 정보

- 프로젝트명: 국민건강보험 소셜 빅데이터 분석 대시보드 개발
- 공개용 프로젝트명: 국민건강보험 소셜 빅데이터 분석 대시보드 개발 (관련 명칭·분석 주제 공개 가능, 사용자 확인, 2026.11.02)
- 수행 기간: 2022.10 ~ 2022.10 (과거 이력서·포트폴리오 기준). 정확한 참여 시작일·종료일은 확인되지 않았다.
- 소속 회사 또는 기관: 코리아리서치인터내셔널 AI빅데이터사업부, 컨설턴트
- 고객사 또는 적용 업무 분야: 국민건강보험·장기요양보험 관련 여론 및 소셜 데이터 분석 업무. 과거 포트폴리오에는 국민건강보험 관련 프로젝트로 소개되어 있으며, 계약상 고객사의 정확한 법인명·계약 구조는 확인되지 않았다.
- 팀 규모 및 구성: 팀 프로젝트 (과거 이력서). 본인은 진행 중이던 프로젝트에 중간 합류했다 (사용자 확인). 프로젝트 인원과 다른 구성원의 세부 역할은 확인 필요.
- 본인의 역할: 대시보드에 사용할 데이터 정리·정제 및 Power BI 대시보드 제작. 토픽·키워드 추출에도 일부 참여한 것으로 기억함 (사용자 설명).
- 관련 회사 경력 또는 학력 기록: [코리아리서치인터내셔널 경력](employment-korea-research-international.md)

## 문제와 목표

- 프로젝트가 시작된 배경과 문제: 과거 자료 기준으로 매스미디어·소셜미디어에서 수집한 국민건강보험 관련 데이터를 분석하고 결과를 전달하는 업무였다. 본인은 중간 합류 후 데이터 정리와 대시보드 제작을 맡았다. 개인의 참여 계기는 중간 투입으로 확인되며, 최초 사업 기획 배경은 확인되지 않았다.
- 달성하려는 목표 및 성공 기준: 정리된 데이터와 주제별 분석 결과를 Power BI 대시보드로 확인할 수 있도록 구현한다. 이력서에는 대시보드 개발 완료가 기재되어 있다. 별도의 정량 목표·검수 기준은 확인 필요.
- 주요 제약 조건: 확인 필요 (구체적인 일정·데이터 품질·운영 환경의 제약은 현재 자료에 없음)

## 본인의 책임과 주도 경험

- 직접 책임진 범위: 프로젝트 중간에 참여해 데이터를 정리하고 Power BI로 대시보드를 제작했다 (사용자 확인, 2026.11.02). 토픽·키워드 추출에도 일부 참여했던 것으로 기억한다고 설명했다. 데이터 정리·BI 제작을 중심으로 담당 경험을 설명하고, 추출 작업의 참여 정도는 이 회상 범위로 기록한다.
- 직접 수행한 작업:
  - 대시보드 제작에 사용할 데이터 정리·정제
  - Power BI를 활용한 분석 결과 대시보드 제작
  - 토픽·키워드 추출 일부 참여 (본인 기억에 근거함. 구체적인 추출 방법과 작업 범위는 확인되지 않음)
- 핵심 의사결정과 그 이유: 확인 필요 (구체적인 설계·도구 선택 결정에 관한 사용자 설명이 없음)
- 팀 또는 고객과 조율한 내용: 확인 필요 (중간 합류와 담당 업무 외 세부 분담·요구사항 협의 내용은 확인되지 않음)
- 어려움과 이를 해결하기 위해 취한 행동: 확인 필요 (현재 답변 및 기존 자료에 구체적인 사례가 없음)

## 수행 방법

- 사용한 데이터의 종류 및 규모: 과거 이력서·포트폴리오 기준으로 매스미디어·소셜미디어에서 수집한 국민건강보험·장기요양보험 관련 정성 데이터. 화면 예시에는 국민건강보험, 장기요양보험, 건강보험공단, 코로나19의 주제 선택이 보인다. 실제 수집 기간·건수·데이터 구조는 현재 확인되지 않았다.
- 분석 방법 또는 AI 접근 방법: 기존 포트폴리오에는 Topic·Keyword 등을 추출하는 데이터 정제와 주제별 분석 결과의 대시보드 구현이 기재되어 있다. 본인은 데이터 정리·Power BI 제작 외에 토픽·키워드 추출에도 일부 참여한 것으로 기억한다고 답했다 (2026.11.02). 추출 알고리즘·사용 도구와 구체적인 작업 분담은 확인되지 않았다.
- 사용한 기술 및 도구: Power BI. 구체적인 Power Query·DAX 사용, 추가 프로그래밍 도구, 배포 방식은 확인되지 않았다.
- 방법을 선택한 이유: 주제별 분석 결과를 대시보드로 전달하기 위한 구현이다. Power BI의 선정 경위는 확인 필요.
- 결과를 검증한 방식 및 비교 기준: 확인 필요 (당시 데이터 정합성 확인·검수 절차에 대한 자료가 없음)

### 기존 포트폴리오에서 확인되는 화면 구성

아래는 24~25쪽에 남아 있는 화면을 읽어 정리한 기능 설명이다. 원본 화면과 차트에 표시된 수치는 포트폴리오 웹 화면에 옮기지 않는다.

| 구성 | 확인되는 내용 |
| --- | --- |
| 주제 선택 | 국민건강보험·장기요양보험·건강보험공단·코로나19 관련 페이지 선택 |
| 매체 구분 | 전체·매스미디어·소셜미디어 선택 |
| 토픽 표시 | 토픽별 규모를 보여주는 트리맵과 월별 추이 그래프 |
| 키워드 표시 | 키워드 네트워크, 워드클라우드, 키워드별 규모 그래프 |

화면은 주제별 분석 결과를 보여주는 구성의 근거다. 토픽·키워드 추출은 일부 참여한 기억으로 기록하며, 알고리즘 개발 여부나 네트워크 분석의 구체적인 수행 주체는 현재 자료에서 확인되지 않았다.

## 결과와 기여

| 지표 또는 변화 | 이전 상태 또는 비교 기준 | 달성 결과 | 산정 기준 또는 확인 근거 |
| --- | --- | --- | --- |
| 데이터 정리 | 대시보드에 사용할 데이터를 준비할 필요 | 프로젝트 중간 합류 후 데이터 정리·정제 수행. 토픽·키워드 추출 일부 참여 | 사용자 답변 및 과거 이력서·포트폴리오. 추출 일부 참여는 본인 기억에 근거하며 세부 범위는 확인되지 않음 |
| 분석 결과의 대시보드 구현 | 주제별 결과를 확인할 수 있는 화면 필요 | Power BI 대시보드 제작 | 사용자 답변, 과거 이력서의 개발 완료 기재, 포트폴리오의 화면 예시 |

- 위 결과 중 본인의 기여로 설명할 수 있는 부분: 중간 투입 상황에서 맡은 데이터 정리와 Power BI 대시보드 제작 실무, 본인의 기억에 따른 토픽·키워드 추출 일부 참여. 과거 포트폴리오의 업무별 기여도 백분율 대신 확인된 업무 범위로 설명한다.
- 수치 외에 확인 가능한 업무 또는 조직의 변화: 분석 결과를 주제별 대시보드 화면으로 확인할 수 있도록 구현했다. 실제 사용 범위와 업무시간 절감 등 후속 효과는 확인되지 않았다.
- 한계 및 개선할 점: 추가 코드·원본 데이터·Power BI 파일은 제공되지 않았으며, 기존 문서와 사용자 설명으로 구현 내용을 확인했다. 현재 자료로 정량 효과나 분석 방법 전체를 재현할 수 없다.

## 채용 담당자용 요약

- 한 문장 요약: 국민건강보험 관련 소셜 데이터 분석 프로젝트에 중간 합류해 데이터 정리와 Power BI 대시보드 제작을 수행했다.
- 문제, 본인의 역할, 결과를 연결한 짧은 설명: 진행 중인 소셜 데이터 분석 프로젝트에서 대시보드에 사용할 데이터를 정리하고, 주제별 토픽·키워드 관련 분석 결과를 살펴볼 수 있는 Power BI 대시보드를 제작했다.
- 이 경험에서 드러나는 역량: 데이터 정리·정제, BI 도구를 통한 분석 결과 시각화, 진행 중인 프로젝트의 담당 업무 수행
