상태: 작성 완료 (사용자 확인, 2026.10.29). 세부 평가 조건 일부는 본인 기억에 근거함.

## 기본 정보

- 프로젝트명: 머신러닝 기반 적응적 인지능력검사 ACT 개발
- 공개용 프로젝트명: ACT(Adaptive Cognitive ability Test)
- 수행 기간: 2021.10.01 ~ 2021.12.31 (프로젝트 수행 확인서·경력증명서 및 사용자 확인 기준). 정식 착수 전에도 개발 가능성에 관한 사전 논의가 있었다.
- 소속 회사 또는 기관: ORP연구소 검사개발센터 용역 참여, 프리랜서 (증빙 기준)
- 고객사 또는 적용 업무 분야: ORP연구소의 기업 채용용 인지능력검사 개발. 최종 사용 기업명은 기재하지 않음.
- 팀 규모 및 구성: 개발 담당자 1명(본인). ORP연구소가 문항·응시 데이터 제공, 산출물 평가 및 일정 관리를 담당했다. 지도교수는 이 프로젝트의 개발에 참여하지 않았다 (사용자 설명).
- 본인의 역할: 데이터 전처리·분석, 검사 개발 방법 설계, Merged Decision Tree의 R 구현, 영역별 검사모형 개발·평가, 내부 도입 및 기술 문서 작성 전담
- 관련 회사 경력 또는 학력 기록: [대학원 학력 기록](education-chung-ang-graduate.md)의 계량심리학·CAT 연구 경험과 연결. 관련 학술 연구는 [AMT 출판 논문 기록](publication-amt-computerized-adaptive-testing.md)으로 정리했다. ORP 프리랜서 경력의 별도 문서화 여부는 추가 확인 후보로 유지.

## 문제와 목표

- 프로젝트가 시작된 배경과 문제: 대학원 연구 과정에서 지도교수와 ORP연구소의 교류를 통해 CAT 개발 가능성을 탐색했고, 이후 상용 인지능력검사 개발을 의뢰받았다. 기존 문항과 응시 데이터를 분석한 결과 IRT(문항반응이론)의 가정 충족에 제약이 있어, 제공된 자료를 활용하는 다른 검사 개발 방법이 필요했다.
- 달성하려는 목표 및 성공 기준: 응답자의 문항 정오 반응에 따라 후속 문항을 선택하고, 적은 문항으로 기존 검사 총점을 예측하는 상용 검사를 개발한다. 일반 결정트리보다 예측 정확도를 높인 영역별 검사모형을 구성하고, ORP연구소의 평가와 내부 도입을 거쳐 상용화에 연결하는 것이 목표였다.
- 주요 제약 조건: 영역별 학습 표본의 규모 차이와 일부 영역의 적은 표본, IRT 가정 충족의 어려움, 별도 개발 지원 인력 부재, 비공개 검사 문항·응시 데이터 및 내부 문서의 보안 제약.

## 본인의 책임과 주도 경험

- 직접 책임진 범위: ORP연구소가 제공한 문항·응시 데이터로부터 검사모형을 설계하고, 알고리즘 구현·성능 비교·검사 개발 및 문서화를 수행했다. 개발 실무는 본인이 단독으로 담당했으며, 고객사는 데이터와 요구사항을 제공하고 결과를 평가했다.
- 직접 수행한 작업:
  - 제공 데이터의 전처리·정제와 기초 통계 분석
  - IRT 가정 충족 여부 검토 및 결정트리 기반 접근 설계
  - 적은 학습 데이터에서의 예측 성능 문제를 다룰 선행연구 탐색
  - Yan 등(2004)의 방법을 참고한 Merged Decision Tree 알고리즘의 R 구현
  - 영역별 일반 결정트리·병합 결정트리 비교 및 최종 검사모형 구성
  - ORP연구소 내부 시스템 도입, 개발 보고서와 Working Technical Document 작성
  - 산출물 발표 및 고객사의 평가 대응
- 핵심 의사결정과 그 이유:
  - **데이터 조건에 맞춘 검사 개발 방법 선택**: 제공된 문항·데이터에서 IRT 접근을 적용하기 어려운 점을 확인하고, 문항 반응으로 전체 검사 총점을 예측하는 결정트리 기반 방법을 선택했다.
  - **노드 병합을 통한 표본 부족 문제 대응**: 일반 결정트리의 반복 분할로 노드별 학습 표본이 줄어드는 문제를 다루기 위해, 총점의 평균 수준이 유사한 노드를 병합하는 방법에 주목했다.
  - **알고리즘 직접 구현**: 당시 활용할 수 있는 구현을 확보하기 어려워 선행연구의 알고리즘을 R로 직접 구현했다. 기존 알고리즘을 프로젝트에 맞게 구현·적용한 경험이다.
- 팀 또는 고객과 조율한 내용: ORP연구소에 필요한 검사 문항 세트와 응시 데이터를 요청하고, 개발 결과를 발표해 평가받았다. 고객사의 일정 관리에 맞춰 모형과 기술 문서를 전달했다.
- 어려움과 이를 해결하기 위해 취한 행동: IRT 접근의 제약을 확인한 뒤 결정트리로 방향을 전환했고, 다시 학습 표본 부족에 따른 예측 성능 문제를 만나 선행연구를 탐색했다. Merged Decision Tree를 직접 구현하고 영역별 비교 평가를 통해 적용했다.

## 수행 방법

- 사용한 데이터의 종류 및 규모: ORP연구소가 제공한 인지능력검사 문항별 정오 반응과 검사 총점. 2024년 포트폴리오 28쪽에는 개발 당시 9개 영역의 문항 수가 15~30개, 영역별 표본이 294~2,716명으로 기재되어 있다. 문항 수·표본 규모의 공개 가능 여부는 사용자 확인을 마쳤다.
- 분석 방법 또는 AI 접근 방법: IRT 가정 검토, 결정트리 회귀, Merged Decision Tree, 영역별 검사 총점 예측. 과거 포트폴리오의 비교 모형은 CART, CTREE, Merged CART, Merged CTREE다.
- 사용한 기술 및 도구: R. 공개 코드에서 `rpart`, `party`, `partykit`, `psych`, `caret`, `foreach` 참조를 확인했다.
- 방법을 선택한 이유: 문항 응답에 따른 검사 경로를 구성하면서, 분할 후 유사한 노드를 병합해 노드별 학습 표본을 확보하고 예측 성능을 개선하고자 했다.
- 결과를 검증한 방식 및 비교 기준: 같은 영역·문항 수 조건에서 상관계수, MAE, RMSE로 모형을 비교했다. 본인의 기억에 따르면 별도 테스트 데이터를 둔 경우도 있었으나, 대부분 10-fold 교차검증으로 평가했으며 표본 수가 적은 영역에서 특히 이 방식을 활용했다. 공개 코드에도 교차검증과 MAE를 기준으로 병합 파라미터를 탐색하는 함수가 있다. 다만 각 성능표가 어느 평가 방식에서 산출되었는지, 데이터 분할 비율과 교차검증의 세부 절차는 현재 정보만으로 확정하지 않는다.

### 공개 코드에서 확인되는 구현

[공개 R 코드][code]는 검사 생성·예측 로직과 교차검증 함수를 포함한다. 확인 기준은 커밋 `6e77f884217efc47d1d55a496e360592e76165e9`이다.

- `predict.merge`: 정오 반응과 분할 기준에 따라 노드를 탐색하고, 병합된 노드로의 이동 및 최종 예측 점수를 처리한다 (2~52행).
- `merged.tree.make`: 노드별 CART 분할과 노드 상태·부모·병합 정보를 관리한다. t 통계량과 Cohen’s d에 기반한 기준을 사용해 노드를 병합하고 학습 데이터를 합친다 (55~368행).
- `cv.10fold.merge`: 전달받은 fold를 사용해 학습·평가를 반복하고, MAE가 작은 병합 파라미터를 탐색한다. `foreach` 기반 병렬 탐색 구문이 포함되어 있다 (371~772행).

저장소는 구현 일부를 공개한 것으로, 내부 데이터·전체 상용 시스템·개발 보고서를 포함하지 않는다. 코드의 내용은 정적으로 확인했으며 실제 고객 데이터로 실행해 성능을 재현한 결과는 아니다.

성능표의 수치는 과거 포트폴리오에 기재된 값이다. 당시 대부분 10-fold 교차검증, 일부 별도 테스트 데이터를 사용했다는 설명은 본인 기억에 근거한다. 위 각 표와 평가 방식의 정확한 대응 관계는 확정되지 않았다.

- 위 결과 중 본인의 기여로 설명할 수 있는 부분: 데이터 분석, 알고리즘 직접 구현, 검사모형 설계·비교·선정, 내부 도입 및 기술 문서 작성을 단독으로 맡아 상용화의 개발 기반을 마련했다. 제품의 제공·판매와 고객 운영은 ORP연구소의 사업 성과로 구분한다.
- 수치 외에 확인 가능한 업무 또는 조직의 변화: ORP연구소가 온라인 ACT 제품을 출시했고, 현재 공식 소개 페이지에서 9개 인지 영역과 직무별 영역 선택 방식 등을 안내하고 있다. [2022.01.27 매일경제 보도][news]는 ORP연구소의 발표를 인용해 ‘국내 최초 머신러닝 알고리즘 기반 인사 선발검사’ 출시로 소개했다. 이 표현은 해당 발표·보도의 범위로 사용한다.
- 한계 및 개선할 점: 전체 데이터·비공개 보고서와 성능 재현에 필요한 실행 환경은 현재 공개 자료에 없다. 각 성능표의 평가 방식과 데이터 분할의 세부 조건은 원자료·원보고서를 대조할 수 있을 때 보완한다.

## 채용 담당자용 요약

- 한 문장 요약: 제한된 인지능력검사 데이터에 맞춰 Merged Decision Tree를 R로 직접 구현하고, 데이터 분석부터 검사모형 개발과 기술 문서화까지 단독으로 수행해 ACT 상용화에 기여했다.
- 문제, 본인의 역할, 결과를 연결한 짧은 설명: IRT 가정과 학습 표본 규모의 제약으로 기존 접근을 적용하기 어려운 상황에서, 노드 병합 기법을 탐색해 생성·예측 로직을 직접 구현했다. 영역별 예측 성능을 비교해 검사모형을 개발하고, ORP연구소의 내부 도입과 상용화를 위한 기술 문서를 제공했다.
- 이 경험에서 드러나는 역량: 데이터 조건에 따른 방법 선택, 선행연구의 알고리즘 구현, 제한된 표본에서의 모델 개선, 고객 요구에 맞춘 검사모형 개발, 개발 전 과정의 독립적 수행과 기술 문서화.
