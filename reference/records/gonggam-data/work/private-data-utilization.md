## 기본 정보

- 업무·담당 지표명: 공공데이터 민간활용 성과. 제공된 2026년 평가편람 및 Excel의 지표 표기는 `1-4-2 공공데이터 민간 활용 성과`다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 입사부터 데이터사업부 선임연구원으로 근무했으며 현재 재직 중이다.
- 수행 기간·해당 연도: 2025·2026년 사업. 개별 착수일·종료일은 미확인. 2024년은 제공 자료에 이 지표의 담당 표시가 없다.
- 적용 기관·지표 범위: 2025년 3개·2026년 8개의 기관·연도 조합. 같은 기관의 다른 연도 기록을 포함하며 독립적인 서비스·논문 11개를 의미하지 않는다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 PU 사례 11개. 아래 기관별 기록에 동일 ID를 사용한다.
- 사용 자료와 확인 기준: `Gonggam_career.xlsx`의 `공공데이터 민간 활용 성과!A1:H12`, `참여사업 목록!F열`, 2026년 평가편람 발췌본의 해당 지표, 사용자 확인 및 민간활용 보완 답변 2026.11.04. Excel의 성과 기재와 평가편람의 요구사항, 본인의 실제 수행 설명을 구분한다.

## 핵심 기여

- 직접 책임진 지표 실무·산출물: 여러 경로에서 민간활용 후보를 발굴하고 당사자에게 데이터 활용 여부·사용처·간담회 참여 의사를 확인했다. 기관과 대표사례를 협의·선정하고, 지원 간담회의 계획안·결과보고서 및 최종 정성보고서·증빙을 작성했다.
- 기관·민간 활용자와의 직접 소통·조율: 기관과 후보의 적절성·파급효과를 논의하고, 민간 활용자에게 실제 데이터 활용 내역과 간담회 참여 가능 여부를 확인했다. 간담회에서는 양측 사이의 커뮤니케이션을 맡아 활용 성과·애로사항·개선사항·지원 방안을 논의하고 기관 지원 활동으로 연결했다.
- 일정 관리와 담당 과업의 완수: 통상 4~6월 발굴·선정, 7~8월 연락·간담회 및 계획안·결과보고서 작성·결재, 9월 정성보고서·증빙 작성의 흐름으로 진행했다. 활동을 기관의 공식 기록으로 만들고 최종 확인·제출까지 연결했다. 기관별 완료·평가 결과는 기존 Excel 기재값을 사용한다.

## 문제와 반복 수행한 업무

### 기관의 요구와 해결할 문제

기관 공공데이터를 민간에서 실제 활용한 사례와 그 활용을 지원한 기관의 노력을 확보해 평가에 제출하는 업무다. 민간 활용자가 만든 앱·웹서비스·논문 등의 성과와 본인이 수행한 사례 확보·기관 지원 활동·보고서 작성을 구분한다.

제공된 2026년 평가편람은 민간 활용 성과의 우수성과 기관 지원 노력을 정성적으로 평가하며 분야 구분 없이 대표사례 1건을 제출하도록 설명한다. 기관 데이터가 활용된 부분, 서비스·논문 등의 실적일자와 관련 증빙, 기관 지원 노력 등이 확인 대상이다. 본인은 후보 발굴과 실제 활용 확인, 기관 협의, 지원 활동 추진 및 증빙 정리를 이어서 수행했다.

### 실제 담당 범위와 반복 절차

1. **공공데이터포털·구글 스칼라에서 1차 후보를 찾는다.** 포털의 기관 데이터 활용사례 중 실적 인정기간에 올라온 사례를 살피고, 논문은 구글 스칼라에서 검색해 기관 데이터 사용이 명시된 내용을 확인했다. 포털의 게시 시점은 후보 검색에 사용한 정보이며 편람의 서비스 개시·업데이트 등 실적일자와 동일하게 취급하지 않는다.
2. **찾지 못하면 API 활용신청 사유를 검토한다.** 기관 데이터의 API 활용신청에 적힌 사용 목적을 읽고 후보를 추가했다. 기관 데이터 사용을 확정한 성과가 아니라 추가로 연락·확인할 후보를 찾는 경로다.
3. **후보가 부족하면 기관 업무 영역의 민간 서비스로 검색을 넓힌다.** 주제가 관련된다는 이유만으로 데이터 활용을 확정하지 않고 실제 사용 여부를 연락해 확인했다.
4. **후보에게 직접 연락해 실제 활용과 간담회 참여를 확인한다.** 해당 기관 데이터를 사용하는지, 어디에 쓰는지, 기관과 간담회를 열어 이용 의견과 지원 방안을 논의할 수 있는지를 물었다.
5. **기관과 대표사례를 협의·선정한다.** 데이터 활용과 간담회 참여 가능성을 확인하고, 후보 중 파급효과가 크다고 판단되는 적절한 사례를 기관과 협의해 결정했다. 파급효과는 선정 시의 판단이며 별도 측정값으로 제시하지 않는다.
6. **지원 간담회를 추진하고 공식 활동으로 정리한다.** 기관과 민간 활용자 사이의 커뮤니케이션을 맡아 활용 내역·성과, 이용 애로사항·개선사항·기관 지원 방안을 논의했다. 계획안·결과보고서를 작성하고 결재를 받아 기관의 공식 활동으로 남겼다.
7. **최종 정성보고서·증빙을 작성해 확인·제출한다.** 사례와 기관 지원 활동의 산출물을 종합해 행정안전부 지표 작성양식에 맞춘 정성보고서·증빙을 마련하고 기관 확인·제출로 연결했다.

- 사용 방법·도구: 공공데이터포털·구글 스칼라 검색, API 활용신청 사유 검토, 기관 업무 영역의 서비스 탐색, 후보 연락과 기관 협의. 별도 크롤링·자동화 코드나 관련 공개 코드는 없다 (사용자 확인, 2026.11.04). 이 지표에 ETC 저장소나 다른 지표의 코드를 연결하지 않는다.
- 주요 판단과 선택 이유: 검색 경로를 단계적으로 넓혀 후보를 확보하되 실제 기관 데이터 사용과 간담회 참여 가능성을 확인하고, 기관과 파급효과·적절성을 논의해 대표사례를 선정했다. 발굴에서 멈추지 않고 지원 활동과 공식 산출물·평가 제출까지 추진한 점을 핵심으로 설명한다.

### 비공개 경험의 처리

직접 웹서비스를 개발·운영해 실적화한 경험은 이번 답변에서 비공개로 요청했다 (2026.11.04). 이 문서와 회사 경력의 공개용 성과·요약에서 제외한다. 이전의 제한적 공개 문구를 현재 허용 범위로 재사용하지 않고, 구체 기관·서비스·기능·화면·코드·PU ID와의 연결도 하지 않는다. 원본 Excel은 그대로 보존하고 공개용 문안에서는 사례 확보·기관 지원 활동과 소통·추진 경험을 중심으로 작성한다.

## 기관 실무자와의 소통·설명·조율

- 직접 소통한 대상의 역할: 담당 지표의 기관 실무자와 민간활용 후보의 관계자. 양측 사이에서 활용 확인·대표사례 선정·간담회와 지원 활동의 커뮤니케이션을 담당했다.
- 확인한 요구·제약: 기관 데이터를 실제 사용하는 후보와 간담회에 참여 가능한 상대를 확보해야 했다. 민간 활용자의 데이터 이용 내역·성과뿐 아니라 실제 이용 애로사항·개선 요구와 기관의 지원 방안을 함께 확인했다.
- 본인이 설명하거나 제시한 내용: 후보에게 기관 데이터의 사용 여부·활용 위치를 묻고, 실제 이용 의견을 듣고 기관의 지원 방안을 논의할 간담회 참여 의사를 확인했다. 기관에는 후보군을 정리해 제시하고 적절성과 기대 파급효과를 협의했다.
- 조율 과정과 합의한 범위: 기관과 대표사례를 결정하고 민간 활용자와 간담회를 추진했다. 간담회에서 기관 데이터 활용과 지원 방안을 논의한 뒤 계획안·결과보고서를 작성·결재받아 공식 활동으로 정리했다.
- 이후 조치와 결과의 근거: 사용자 설명의 간담회·결재·보고서 작성 과정과 Excel의 간담회 추진·정성보고서·증빙 제출 기재. 특정 갈등이나 지연이 있었던 대표 사례는 생략한다.

## 일정 관리와 과업 완수

### 실적 인정기간과 기관별 수행 기한

- 제공된 **2026년 평가편람**은 해당 지표의 실적 인정기간을 **2025.11.15 ~ 2026.09.30**으로 기재한다. 기준은 편람의 `1-4-2` 절, 실적 불인정 사례 ①과 그 설명이다.
- Excel A2에는 인정기간을 ‘보통 전년도 9월부터 올해 9월까지’라고 일반적으로 설명한다. 정확한 연도별 기준과 구분하며, 2026년 기간을 그 설명만으로 바꾸지 않는다. 2025년의 정확한 인정기간은 현재 자료로 확정하지 않는다.
- 실적 인정기간은 서비스 개시·업데이트나 논문 승인·출판 등 사례의 실적일자를 확인하는 범위다. 본인의 착수일·간담회일·기관 검토 마감·최종 제출 기한과 동일한 날짜로 취급하지 않는다.

### 통상 수행 일정과 관리

| 통상 시기 | 본인이 수행한 일 | 다음 단계로 연결한 내용 |
| --- | --- | --- |
| 4~6월 | 사업이 본격화되면 후보군을 발굴·정리하고 기관과 적절성·파급효과를 협의해 사례 선정 | 대표사례와 지원 활동의 대상 확보 |
| 7~8월까지 | 민간 활용자와 연락해 간담회를 개최하고 계획안·결과보고서 작성·결재 진행 | 기관 지원 노력을 공식 활동과 산출물로 확보 |
| 9월 | 누적 활동·산출물을 종합해 행정안전부 작성양식의 정성보고서·증빙 작성 | 기관 확인 및 최종 평가 실적 제출 |

- 위 일정은 사용자가 설명한 통상 수행 흐름이며 모든 기관의 정확한 계약·간담회·제출일이 아니다. 후보 확인 연락과 간담회 추진은 단계에 따라 이어졌다.
- 회사 경력에서 확인한 기관 실무자와의 매일 진행 상황·후속 업무 소통을 바탕으로 여러 기관의 활동과 산출물을 제출까지 연결한 경험으로 설명한다.
- 특정 자료 지연·회신 지연과 대응 사례는 제공되지 않았고 별도로 요구하지 않는다. 통상 단계별 진행과 기존 Excel의 완료·제출 결과를 근거로 기록한다 (사용자 요청, 2026.11.04).
- 완료·제출 결과는 Excel G2:G12를 따른다. 세부 날짜나 추가 완료율을 만들지 않으며 2026년 평가 결과는 제공 자료의 미공개 상태를 유지한다.

### 개별 애로사항 사례 생략과 공통 수행 경험

사용자는 마땅히 떠오르는 애로사항 대표 사례가 없어 해당 질문을 생략하기를 요청했다 (2026.11.04). 이를 미해결 질문이나 완료를 막는 조건으로 남기지 않는다. 위 11개 PU ID는 기관별 실적의 근거 연결용으로 유지하고, 특정 기관의 문제·설득·합의 이야기를 새로 만들지 않는다.

경력 서술은 **후보 발굴 → 실제 활용·참석 의사 확인 → 기관과 대표사례 협의 → 간담회·지원 방안 논의 → 계획안·결과보고서 결재 → 최종 정성보고서·증빙 제출**의 반복 수행 과정으로 구체화한다. 사용자 요청대로 여러 기관의 다수 후보를 찾고 양측을 연락·조율해 대표사례와 공식 지원 활동으로 이어간 커뮤니케이션·추진력을 강조한다.

## 채용 담당자용 요약

- 한 문장: 다수 기관의 민간활용 후보를 단계적으로 발굴·확인하고, 기관과 활용자 사이의 협의를 통해 대표사례 선정부터 지원 간담회·공식 활동화·평가 제출까지 추진했다.
- 짧은 서술: 공공데이터포털·논문 검색을 시작으로 API 활용신청 사유와 기관 업무 영역의 민간 서비스까지 후보 탐색을 넓혔다. 후보에게 직접 연락해 기관 데이터의 실제 사용과 간담회 참여 의사를 확인하고, 기관과 적절성·파급효과를 협의해 대표사례를 선정했다. 이후 양측의 소통을 맡아 활용 성과·애로사항·지원 방안을 논의할 간담회를 추진하고 계획안·결과보고서의 결재를 거쳐 공식 활동으로 정리했다. 이 활동과 산출물을 최종 정성보고서·증빙으로 연결하며 다수 기관의 실적을 발굴·선정·지원·제출까지 이어가는 커뮤니케이션과 추진력을 쌓았다.
- 드러나는 역량: 단계적인 후보 발굴·사실 확인, 기관과 민간 활용자의 요구를 연결하는 커뮤니케이션, 후보 비교·협의와 대표사례 선정, 활동 기획·추진 및 공식 문서화, 단계별 일정·최종 제출 관리.

### 질문 답변과 보완 상태

1. 발굴·확인 방법: 포털·구글 스칼라, API 활용신청 사유, 기관 영역의 민간 서비스 순으로 탐색을 넓히고 후보 연락으로 실제 활용·참석 가능성을 확인하는 과정을 반영했다. 별도 코드가 없음을 확인했다.
2. 애로사항 대표 사례: 사용자가 생략을 요청해 공통 수행 과정 중심으로 작성했다. 추가 질문이나 가상의 기관별 사례를 만들지 않는다.
3. 일정·성과·강조점: 통상 4~6월 발굴·기관 협의·선정, 7~8월 간담회·계획안·결과보고서·결재, 9월 정성보고서·증빙 작성 흐름을 반영했다. 최종 완료·평가 상태는 Excel로 충분하다는 답변을 따르고, 다기관 커뮤니케이션·추진력을 핵심으로 정리했다.
4. 공개 범위: 직접 웹서비스 개발·운영·실적화 경험은 최신 비공개 요청을 적용해 공개용 문안에서 제외했다.
