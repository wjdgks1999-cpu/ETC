# 담당 업무: 데이터 분석·정책활용 실적 및 성과

[공감데이터 전체 안내](../README.md) · [평가제도와 업무 연결](../evaluation/indicators-2026.md)

상태: 작성 완료·사용자 확인 (2026.11.04). 원본 대조와 보완 질문 3개 답변을 반영한 뒤 사용자가 내용을 확인하고 다음 업무 진행을 요청했다. 기존 분석과 실제 정책활용의 연결을 찾아 기관 확인·공식 문서화·등록·사후관리·최종 제출까지 추진한 경험과 언론진흥재단의 직접 분석을 구분했다. 추가자료·추가 질문은 없으며, 자료·회상·실행 재현의 구분과 공개 제한은 아래와 같이 유지한다.

## 기본 정보

- 업무·담당 지표명: 데이터 분석·정책활용 실적 및 성과(AN). Excel의 `3-1 데이터 분석·활용 실적 및 성과` 아래 정량 `3-1-1 데이터 분석·정책활용 실적`, 정성 `3-1-2 분석 결과의 정책활용 노력 및 성과`를 구분한다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 담당한 업무다.
- 수행 기간·해당 연도: 2024~2026년 사업. 개별 사업의 참여 기간과 과제별 분석 기간, 실적 인정기간은 구분한다.
- 적용 기관·지표 범위: 2024년 4개·2025년 9개·2026년 9개, 총 22개 기관·연도·업무 조합. 본인이 직접 수행한 분석 22건이라는 뜻이 아니다. 한국교육학술정보원 2026년의 교육청 3곳은 한 상위 조합 안의 하위 실적이다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 기존 AN ID 22개를 사용한다. 직접 분석 사례는 `GG-2025-12-AN`이다.
- 사용 자료와 확인 기준: Excel S0·S5, 2026년 평가편람 G1의 해당 지표, 언론진흥재단 수행계획서 R1·분석결과보고서 R2·정책활용결과보고서 R3, 기존 사용자 확인과 AN 보완 답변(2026.11.04). 아래 근거 위치는 내부 관리용이다.

## 핵심 기여

- 직접 책임진 실무·산출물: 기관의 분석결과보고서 원문과 실제 정책활용 활동을 찾아 연결 관계를 정리했다. 분석기간·목적·방법·데이터·결과·정책활용 결과를 구체적으로 설명할 수 있는 과제를 기관 담당자와 확인하고, 보고서·공식 결재 문서로 실적화해 등록·승인으로 연결했다.
- 기관 실무자와의 소통·조율: 분석과 정책활용의 연결은 있었지만 문서로 정리되지 않은 과제를 찾아 담당자에게 연결 근거와 실적 제출 가능성을 설명·확인했다. 발굴·결과 및 활용의 공식화, 실무진과의 운영·개선방안 사후관리 회의를 추진하고 최종 정성보고서·증빙으로 종합했다. 2024년 산출물 중심, 2025년 대부분 지표 전반 수행, 2026년 맡은 지표의 독립 수행이라는 역할 변화는 유지한다.
- 직접 분석과 업무 활용 연결: 한국언론진흥재단이 제공 가능한 데이터 후보를 받은 뒤 GOAD 문의 분석 주제를 직접 선정했다. 문의 데이터를 분석하고 결과와 개선안을 기관에 설명·전달했다. 개선 반영은 재단이 수행했으며, 본인은 반영 내용을 받아 보고서로 작성해 기관에 전달했다.
- 일정 관리와 담당 과업의 완수: 통상 5~6월 발굴, 7~8월 보고서 작성·공식 결재 문서화, 8월까지 사후관리, 9월까지 정성보고서·증빙 작성을 진행했다. 정량은 기관별 목표 과제의 시스템 등록·승인으로, 정성은 활동 종합·최종 자료 작성과 기관 확인·제출로 연결했다. 기관별 실적·등급은 Excel 기재값을 따른다.

## 문제와 반복 수행한 업무

### 기관의 요구와 해결할 문제

기관이 수행한 데이터 분석이 어떤 목적·방법·결과를 가졌고 기관의 정책이나 서비스에 어떻게 활용되었는지, 평가에서 확인할 수 있는 보고서와 공식 증빙으로 연결하는 업무다. 이미 수행된 기관 과제의 발굴·정리와 직접 분석 수행을 구분한다.

정량 실적은 과제별 분석·활용 내용과 등록 결과를, 정성 실적은 발굴부터 분석·정책활용·사후관리로 이어지는 기관 활동과 대표 과제의 노력·성과를 설명한다. 같은 과제를 두 하위지표에서 설명했다고 분석 건수를 두 번 합산하지 않는다. 2024년 정성 하위지표가 없었다는 내용은 Excel 기재에 근거하며, 2026년 편람을 이전 연도에 소급 적용하지 않는다.

### 일반적인 기존 과제 발굴·실적화 과정

다음은 Excel S5!A2:B2와 사용자 보완 답변(2026.11.04)을 종합한 공통 수행 과정이다. 기관 소통의 담당 범위는 위 연도별 역할 변화와 함께 읽는다.

1. **기관 내부의 과제 발굴활동을 추진한다.** 지표 착수 시 실적 인정기간 내 분석·정책활용 과제를 실무부서별로 제출하도록 하는 발굴활동을 진행했다. 제출된 과제가 실적화 가능하면 그 자료를 바탕으로 정리했다. 사용자는 이 경로만으로 과제가 확보되는 경우는 드물었다고 설명했다.
2. **분석 원문과 실제 정책활용 활동을 찾아 연결한다.** 기관에서 찾을 수 있는 분석결과보고서 원문과 관련 정책활용 활동을 검토했다. 기관이 분석 결과를 업무에 활용했더라도 그 연결을 설명하는 문서가 남아 있지 않은 경우가 있어, 어떤 분석 결과가 어떤 정책활동에 활용되었는지 정리했다.
3. **실적 적합성을 판단하고 기관 담당자와 확인한다.** ① 분석기간, ② 분석목적, ③ 분석방법, ④ 활용데이터, ⑤ 분석결과, ⑥ 정책활용 결과를 구체적으로 작성할 수 있는지 확인했다. 연결 관계를 담당자에게 설명하고 해당 과제를 기관 실적으로 제출할 수 있음을 확인했다. 실제 분석·활용의 근거에 기반해 판단한 경험이다.
4. **보고서와 공식 문서로 실적화한다.** 수행계획서·분석결과보고서·정책활용결과보고서를 작성하고, 결과를 기관 공식 결재 문서로 보고해 분석·활용 활동을 공식화했다. 기수행 사실과 활용 관계를 기관에서 확인받아 정리했다.
5. **범정부 데이터분석시스템에 등록하고 승인받는다.** 기관별 목표 과제 수에 맞춰 분석사례를 등록하고 승인으로 연결해 정량 지표 3-1-1을 마무리했다. 기관별 건수·기재 결과는 아래 Excel 대조표를 따른다.
6. **정량 실적화와 함께 정성평가에 필요한 활동을 추진한다.** 2025·2026년에는 기관 담당자와 발굴활동·분석결과 및 활용의 공식화를 진행하고, 과제 실무진과 향후 운영·개선방안을 논의하는 사후관리 회의 등을 추진했다. 등록 건수 확보와 기관의 체계적인 수행 활동을 함께 관리했다.
7. **정성보고서·증빙을 종합해 기관 확인·제출로 연결한다.** 과제 실적과 발굴·공식화·사후관리 활동을 최종 정성보고서와 증빙으로 작성했다. 기관 확인·최종 제출까지의 공통 책임 범위는 기존 회사 경력 답변과 연결한다.

기존 실적이 없으면 데이터를 받아 분석과제를 구성·수행하고 활용을 지원하는 방식도 S5!B2에 기재되어 있다. 현재 직접 분석한 사례로 확인된 것은 한국언론진흥재단 2025년이며, 다른 AN 조합의 발굴 과제를 본인의 직접 분석으로 확대하지 않는다.

### 기술·분석 방법

일반적인 발굴·실적화 업무의 핵심은 기관 자료 확보, 분석·활용 사실의 구조화, 활동·보고서·증빙 작성과 등록이다. 언론진흥재단에서 확인된 Python·텍스트 분석 도구를 전체 기관에 일괄 적용했다고 서술하지 않는다. 별도의 발굴 자동화나 ETC 코드 적용도 현재 확인되지 않았다.

주요 판단은 이미 존재하는 분석과 실제 활용을 설명할 근거가 있는지, 위 여섯 항목을 구체적으로 작성할 수 있는지였다. 기관 실무부서의 제출만 기다리지 않고 원문·활용 활동을 직접 찾아 담당자와 연결 관계를 확인함으로써 실적화할 과제를 확보했다.

## 기관 실무자와의 소통·설명·조율

- 직접 소통한 대상: 담당 지표의 기관 실무자. 2024년에는 기관 커뮤니케이션을 대부분 상사가 담당했고, 본인은 산출물 작성에 집중했다.
- 확인된 공통 행동: 2025년부터 대부분의 담당 지표에서 수행 방법과 일정을 설명·설득하고, 기관과 진행 상황·후속 업무를 소통하며 최종 실적을 기관에서 확인받아 제출했다. 2026년에는 본인이 맡은 지표를 독립적으로 수행했다.
- 확인한 실무 제약: 부서별 발굴 요청만으로 제출 가능한 과제를 확보하기 어려웠고, 이미 수행된 분석과 실제 정책활용 사이의 연결을 설명하는 문서가 부족한 경우가 있었다. 이는 사용자 설명의 공통 경험이며 모든 기관의 동일한 상황으로 일반화하지 않는다.
- 본인이 설명·확인한 내용: 분석 원문과 정책활용 활동의 연결 관계, 여섯 항목을 작성할 수 있는 근거, 해당 과제의 기관 실적 제출 가능성. 이를 담당자에게 설명하고 확인받아 보고서·공식 결재 문서화로 연결했다.
- 담당자·실무진과 추진한 활동: 과제 발굴, 분석결과·활용 활동의 공식화, 과제 실무진과 향후 운영·개선방안을 논의하는 사후관리 회의. 활동과 결과를 최종 정성보고서·증빙으로 정리했다.
- 언론진흥재단 역할 분담: 기관이 제공 가능한 데이터 후보를 전달했고 본인이 분석 주제를 선정했다. 본인은 직접 분석 후 결과·개선안을 설명·전달하고, 재단이 반영한 개선 내용을 전달받아 보고서로 작성·기관에 전달했다. 사용자는 주제 협의부터 활용 증빙·최종 제출까지 대부분을 담당했다고 설명했으며, 구체적인 본인 행동은 이 범위로 기록한다. UI·매뉴얼 개선 반영은 재단의 수행이다.
- 확인 근거: 실제 발굴·협의·사후관리·역할 분담은 사용자 보완 답변, 실적화·등록·제출과 지표 결과는 Excel, GOAD 분석·개선 결과는 보고서다. 자료에 없는 갈등·지연 사례를 추가하지 않는다.

## 채용 담당자용 요약

- 한 문장: 공공기관의 기존 분석과 실제 정책활용을 연결해 담당자 확인·공식 문서화·등록·사후관리·평가 제출까지 추진하고, 한국언론진흥재단에서는 분석 주제 선정부터 직접 분석·개선안 전달·활용 결과 보고까지 수행했다.
- 짧은 서술: 실무부서의 제출만으로 과제가 확보되기 어려운 상황에서 분석결과보고서 원문과 실제 정책활용 활동을 찾아 연결했다. 분석기간·목적·방법·데이터·결과·활용을 구체화해 담당자에게 실적 제출 가능성을 설명·확인하고, 보고서·기관 결재 문서로 공식화한 뒤 시스템 등록·승인으로 연결했다. 기관 담당자와 과제 실무진의 사후관리 활동을 추진하며 통상 5~6월 발굴, 7~8월 실적화, 8월까지 사후관리, 9월까지 최종 정성보고서·증빙 작성을 진행했다. 한국언론진흥재단에서는 제공 가능한 데이터 후보 중 GOAD 문의 분석을 선택하고 Python·Kiwi·TF-IDF·BERTopic으로 직접 분석했다. 결과와 개선안을 설명·전달하고 재단이 반영한 UI·UX·매뉴얼 개선 내용을 받아 보고서로 정리했다.
- 드러나는 역량: 분석·활용 근거의 발굴과 적합성 판단, 기관 실무자에게 연결 관계를 설명·확인하는 소통, 한국어 텍스트 분석·결과 해석·개선안 제시, 공식 활동·사후관리 추진, 단계별 산출물·일정·최종 제출 관리.

### 질문 답변과 검토 상태

1. 추가자료: 없다는 답변을 받았다. 기존 Excel·편람·언론진흥재단 보고서 3종과 사용자 설명으로 작성한다.
2. 일반 수행 과정·일정: 부서별 발굴 요청에만 의존하지 않고 분석 원문과 실제 정책활용의 연결을 찾아 담당자에게 설명·확인한 과정, 보고서·결재 문서화·등록·승인, 사후관리 회의와 정성보고서·증빙 작성의 통상 일정을 반영했다.
3. 언론진흥재단 분담: 기관의 데이터 후보 제시 후 본인이 주제를 선택하고 분석·결과 설명·개선안 전달을 수행했다. 개선 반영은 재단이 맡고, 본인은 반영 내용을 받아 보고서로 작성·기관에 전달한 범위를 반영했다. 활용 증빙·최종 제출까지 대부분을 맡았다는 설명은 확인된 구체 행동 및 기존 Excel 결과와 연결했다.

보완 질문 3개는 모두 답변·반영했다 (2026.11.04). 이후 사용자의 내용 확인·다음 업무 진행 요청을 반영해 작성 완료로 정리했다. 현재 추가 질문은 없으며, 개별 기관의 특별한 애로사항·정확한 날짜·추가 완료 증빙을 일괄 요구하지 않는다. 완료 표시는 미확인 수치나 코드 실행을 새로 검증했다는 뜻이 아니다.
