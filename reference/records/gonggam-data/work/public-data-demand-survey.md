# 담당 업무: 대국민 공공데이터 활용 수요조사

[공감데이터 전체 안내](../README.md) · [평가제도와 업무 연결](../evaluation/indicators-2026.md)

상태: 작성 완료·사용자 확인 (2026.11.04). Excel S0·S2·2026년 편람·공개 코드 대조와 두 차례 보완 답변을 반영한 뒤 사용자가 내용을 확인하고 다음 업무를 새 세션에서 시작하기로 했다. 현재 추가 질문은 없다. 코드 실행·분류 성능 미재현, 지표 결과의 범위와 공개 제한은 유지한다.

## 기본 정보

- 업무·담당 지표명: 대국민 공공데이터 활용 수요조사(SU). Excel S2!A2는 `1-4-3 공공데이터 활용 지원` 활동 중 하나로 설명한다. 수요조사를 독립 평가지표로 새로 만들지 않는다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 담당한 업무다.
- 수행 기간·해당 연도: 2024·2025년 사업. 2024년 4개·2025년 7개, 총 11개 기관·연도·업무 조합이다. 통상 4~5월 설문지 작성, 6월 조사, 7월 결과보고서 작성·최종 기관 확인을 진행했다 (사용자 보완 답변). 개별 기관의 정확한 날짜·표본 규모는 확정하지 않는다. 2026년은 제공된 Excel에 SU 담당 표시가 없다.
- 적용 기관·지표 범위: 아래 SU ID 11개. 같은 기관의 다른 연도 기록을 포함하며 고유 기관 수·응답자 수·개별 설문 문항 수와 구분한다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 기존 SU ID 11개를 유지한다. `농정원`은 기존 기준대로 `농림수산식품교육문화정보원`으로 통일한다.
- 사용 자료와 확인 기준: Excel S0 `참여사업 목록!E열`, S2 `대국민 공공데이터 활용 수요조사!A1:H12`, 기존 확정 답변·공개 제한, SU 보완 답변 (2026.11.04), 평가편람 G1의 활용지원 절, ETC의 `5. answer_classification_Langchain` 공개 파일 7개. 자료 기재·개인 수행 설명·코드 구현·실행 재현을 구분한다.

## 핵심 기여

- 설문 설계·기관 확인: 기관과 조사 영역을 먼저 정하고 회사의 기존 문항은행을 바탕으로 기관에 맞는 문항·보기를 작성했다. 활용 현황·사례·만족도·개선 방향을 중심으로 하고 요구에 따라 AI 서비스 개발에 필요한 개방 데이터 수요 등을 포함했다. 기관 확인·수정을 거쳐 설문지를 확정했다.
- 온라인 조사·홍보 연결: 확정 설문을 온라인 설문으로 옮기고 홍보 포스터를 만들어 기관에 전달했다. 기관이 홍보를 맡고 수행팀도 여러 커뮤니티에 홍보 글을 게시했다. 구체적인 플랫폼·응답자 모집 규모나 개인별 게시 분담은 새로 확정하지 않는다.
- 객관식 분석: 기술통계·비율 분석·시각화를 수행했다 (S2!B2). 표본 규모·응답률·가중치·모집단 대표성이나 특정 통계 도구는 자료 없이 추정하지 않는다.
- 주관식 분석·검토: 응답을 정리해 분류체계를 세우고 이를 기준으로 라벨링했다. LangChain으로 1차 처리한 뒤 사람이 재검토했으며, 라벨링 완료 후 수치화하고 대표 답변을 선정했다. 공개 코드는 담당했던 대부분 기관의 처리·수치화·보고서 기재를 설명하는 대표 구현으로 연결한다. 모든 SU ID·연도에 동일 설정을 적용했다고 단정하지 않는다.
- 결과보고서·일정: 조사·객관식 분석·주관식 집계와 대표 답변 등을 종합해 보고서를 작성하고 기관에 제공했다. 통상 4~5월 설문지 작성 → 6월 조사 → 7월 보고서 작성·최종 확인으로 진행했다. 실제 개방·서비스 개선 반영이나 최종 평가시스템 제출까지 본인이 수행했다고 확대하지 않는다.
- 결과: 11개 행 모두 해당 활용지원 지표의 ‘우수’가 기재되어 있다. 수요조사 하나만의 독립 평가 등급이나 기관 전체 종합 등급으로 쓰지 않는다.

## 문제와 반복 수행한 업무

### 기관의 요구와 해결할 문제

국민이 기관 공공데이터를 어떻게 활용하고 얼마나 만족하는지, 어떤 개선·추가 개방을 원하는지 조사하고 정리하는 업무다. 기관마다 필요한 조사 영역을 먼저 협의하고 기존 문항을 기관의 데이터·업무에 맞게 조정했다. AI 서비스 개발에 필요한 개방 데이터처럼 기관이 추가로 요청하는 수요도 문항에 반영했다. Excel S2!A2의 활용지원 활동 맥락과 연결해 설문 설계·기관 확인에서 응답 분석·결과보고서까지의 실무를 설명한다.

제공된 2026년 편람 `1-4-3 공공데이터 활용 지원`은 지원 활동·성과를 평가하며 수요조사를 인정 활동의 예로 든다. 제출 활동 5건이라는 설명을 수요조사 5회를 수행했다는 뜻으로 사용하지 않는다. 이 편람은 지표 맥락을 이해하는 참고 자료이며 2024·2025년의 정확한 배점·인정기간·양식·평가 결과를 확정하는 근거로 소급 적용하지 않는다.

### 실제 수행 과정과 역할 분담

1. **기관과 조사 영역을 협의한다.** 활용 현황·사례, 만족도, 개선 방향 등 기관이 파악하려는 영역을 먼저 정했다. 기관이 요구하면 AI 서비스 개발을 위해 우선 개방할 데이터 수요 등의 문항도 포함했다. 특정 문항을 모든 기관·연도에 동일하게 적용했다고 일반화하지 않는다.
2. **기존 문항은행을 활용해 기관에 맞는 문항·보기를 구성한다.** 회사가 보유한 문항은행을 바탕으로 영역별 문항을 만들고 기관의 특성에 맞춰 표현·선택지를 작성했다. 문항은행을 본인이 새로 구축했다는 뜻은 아니다.
3. **기관 확인·수정을 거쳐 설문지를 확정한다.** 초안을 기관에 전달해 확인받고 수정을 이어간 뒤 최종 확인을 받았다. 이 협의 과정의 연도별 소통 분담은 2024년 상사 중심·2025년 대부분 지표 전반 수행이라는 기존 답변과 함께 읽는다.
4. **온라인 설문으로 전환하고 홍보를 준비한다.** 확정 설문지를 온라인 설문으로 옮긴 뒤 포스터를 제작해 기관에 전달했다. 기관이 홍보하고 수행팀도 여러 커뮤니티에 홍보 글을 게시했다. 조사 플랫폼을 직접 개발했거나 표본의 모집단 대표성을 확보했다고 서술하지 않는다.
5. **객관식 결과를 기술통계·시각화로 정리한다.** 조사가 끝난 뒤 응답을 분석했다. 기술통계·비율 분석·시각화는 S2!B2와 보완 답변에 근거한다. 특정 검정·가중치·통계 패키지는 자료 없이 추가하지 않는다.
6. **주관식 응답을 정리해 분류체계를 만든다.** 실제 답변을 살펴 범주를 세운 뒤 그 기준으로 라벨링했다. 기관별 최종 범주 수·내용을 공개 예제의 7개·9개 범주로 일괄 대체하지 않는다.
7. **LangChain 1차 분류 후 사람이 재검토한다.** 첫 라벨링을 LangChain으로 처리하고 이후 사람이 재검토했다. 라벨링이 끝나면 수치화하고 대표 답변을 선정했다. 검토자의 개인별 분담·전수 검수 여부·수정률·정확도는 제시되지 않았으므로 확정하지 않는다.
8. **분석 결과를 종합한 보고서를 기관에 제공한다.** 객관식 결과와 주관식 집계·대표 답변 등을 종합해 결과보고서를 작성하고 기관에 전달했다. 시사점·개선 수요는 분석 결과를 보고서로 정리한 범위로 설명하며 별도의 구두 발표·실제 개방 개선 실현을 추정하지 않는다.

## 기관 실무자와의 소통·설명·조율

- 기존 회사 답변에 따르면 2024년에는 본인이 산출물 작성에 집중하고 기관 소통은 대부분 상사가 맡았다. 2025년에는 대부분의 담당 지표를 전반적으로 수행했다. 이 역할 변화를 유지한다.
- 조사 영역 협의: 기관이 파악하려는 활용 현황·사례·만족도·개선 방향을 확인하고, 필요하면 AI 개발 관련 개방 수요를 포함했다. 어떤 기관이 어떤 추가 문항을 요청했는지는 새로 배정하지 않는다.
- 문항 확정: 수행팀이 기존 문항은행을 바탕으로 기관에 맞춘 문항·보기를 작성하고 기관 담당자에게 확인받으며 수정을 이어갔다. 최종 확인을 받은 뒤 온라인 설문으로 옮겼다. 확인·수정의 반복을 실제 조율 행동으로 설명한다.
- 배포·홍보 분담: 수행팀이 홍보 포스터를 만들어 기관에 전달했고 기관이 홍보했다. 수행팀도 여러 커뮤니티에 조사 홍보 글을 게시했다. 기관과 수행팀의 참여자 모집 활동을 구분하며 전체 배포를 기관 또는 본인 한쪽의 단독 수행으로 쓰지 않는다.
- 결과 전달: 응답 분석과 주관식 집계·대표 답변을 종합한 결과보고서를 기관에 제공하고 통상 7월에 최종 확인을 진행했다. 별도 구두 설명·기관의 실제 개방·서비스 개선 반영은 확인된 것으로 추가하지 않는다.
- 다른 지표의 방문 설명·제공 거절 대응·사후관리 회의를 SU의 실제 일화로 옮기지 않는다.

## 채용 담당자용 요약

- 한 문장: 기관과 조사 영역을 협의해 맞춤 설문을 확정하고 온라인 조사·홍보로 연결했으며, 객관식 분석과 LangChain 1차 분류·사람 재검토를 거친 주관식 결과를 보고서로 정리해 기관에 전달했다.
- 짧은 서술: 기관이 알고자 하는 활용 현황·만족도·개선 방향 등을 먼저 협의하고 회사의 기존 문항은행을 바탕으로 기관에 맞는 문항·보기를 작성했다. 기관 확인·수정을 거쳐 확정한 설문을 온라인으로 옮기고 포스터 제작·기관 홍보·커뮤니티 홍보로 조사를 진행했다. 객관식은 기술통계·시각화로 정리하고 주관식은 응답 기반 분류체계를 만든 뒤 LangChain 1차 라벨링·사람 재검토를 거쳐 수치화하고 대표 답변을 선정했다. 통상 4~5월 문항 작성, 6월 조사, 7월 결과보고서 작성·기관 최종 확인까지 이어갔다. 담당했던 대부분 기관의 주관식을 공개 대표 코드의 방식으로 처리했으며, 활용지원 지표 우수와 수요조사 단독 평가·분류 정확도는 구분한다.
- 드러나는 역량: 기관 요구를 조사 영역·문항으로 구체화하는 소통, 기존 문항의 기관 맞춤 작성·수정, 온라인 조사·홍보 연결, 객관식 분석, 응답 기반 분류체계 설계·AI 분류 후 사람 검토, 정량 집계와 대표 답변을 결합한 보고서 작성·단계별 일정 추진.
