- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 담당한 업무다.

- 적용 기관·지표 범위: 한국산업기술진흥원 2026년 한 기관·연도·업무 조합. 기관의 포털 개방 실적 3건과 업무 조합 1개를 구분한다.

## 핵심 기여

- 후보 발굴·선정: 기관 제시 후보와 한국산업기술진흥원이 기존에 개방·공유한 데이터를 모두 검토했다. 개인정보 컬럼을 포함하고 충분한 데이터량을 확보할 수 있으며, 컬럼별 가상값 생성이 가능하고 기관이 개방할 수 있는 데이터를 후보로 골랐다.
- 기관 설명·확인: 후보가 해당 지표의 실적이 될 수 있는 이유, 합성데이터 생성 방법, 이후 안전성·유용성 검증 과정과 결과보고서 등 산출물을 기관 담당자에게 설명했다. 담당자 동의 후 원본 데이터를 받아 다음 작업으로 이어갔다.
- 기술 실무·팀 공유: 원본의 컬럼별 제외 여부·정제 방법·컬럼 간 관계와 합성 시 주의점을 검토한 뒤 Python 오픈소스 라이브러리로 생성·평가했다. 공통 생성·평가 코드를 작성해 팀에 공유한 사실은 S7!B2와 연결한다.
- 관계자 검증·후속 분담: 코드 평가 결과를 바탕으로 여러 관련자와 안전성·유용성 검증을 진행했다. 수행팀이 검증 결과보고서 작성·산출물 정리를 맡고, 기관 담당자는 확인·결재 문서화·평가자료 제출·포털 등록을 맡았다. 수행팀의 보고서 작성은 개인 단독 집필로 확대하지 않는다.
- 일정과 결과: 5~6월 발굴 → 7월 생성 → 8~9월 검증을 진행했다. Excel에는 포털 합성데이터 3건 개방 완료가 기재되어 있으며, 본인의 후보 협의·생성·평가·검증 참여와 기관의 최종 제출·등록을 구분한다. 평가 인정 결과는 미정이다.

## 문제와 반복 수행한 업무

### 기관의 요구와 해결할 문제

기관 데이터 중 합성데이터로 생성해 민간에 개방할 후보를 찾고, 생성·평가·관계자 검증과 공식 산출물로 연결하는 업무다. 사용자는 개인정보 컬럼과 충분한 데이터량, 가상값을 생성할 수 있는 컬럼 구성, 기관 입장에서의 개방 가능성을 함께 고려했다고 설명했다. 개인정보가 있다는 이유만으로 선정하거나 기존 개방·공유 데이터를 그대로 실적으로 제출한 것으로 단순화하지 않는다.

개인정보·민감정보를 포함한 데이터를 대상으로 한다는 점은 제공된 편람과 연결한다. 충분한 데이터량과 컬럼 구성은 사용자가 설명한 실제 선정 기준으로 기록하며, 구체적인 최소 행 수·건수는 새로 만들지 않는다. SH의 3열·50행 기준을 SY에 적용하지 않는다.

Excel S7과 보완 답변에서 개인정보보호위원회의 합성데이터 생성·활용 안내서를 기준으로 코드를 작성하고 생성 결과를 평가했다고 설명했다. 당시 준수 기준에 관한 사용자 설명으로 기록하며, 이번 정적 열람으로 안내서 준수나 안전성을 독립 검증한 것은 아니다.

2026년 편람의 `1-5`는 민간 대상 가명정보 제공 또는 공공데이터포털을 통한 합성데이터 개방을 평가한다. 기관 간 공유 지표 `4-5`는 기관공유시스템을 통한 공유를 대상으로 하므로, 포털 개방 3건이 기재된 이 사례는 **개방 지표**로 정리한다. 동일 실적을 두 지표에 중복 합산하지 않는다.

### 확인된 수행 순서와 역할 범위

1. **공통 생성·평가 코드를 마련해 팀에 공유했다.** 적절한 원천데이터가 선정되었다는 전제에서 합성데이터 생성·평가 코드를 작성했다 (S7!B2). 코드 공유 자체를 다른 기관의 직접 수행 실적으로 늘리지 않는다.
2. **기관 제시 후보와 기존 개방·공유 데이터를 검토했다.** 기관에서 제시한 후보와 그동안 개방·공유한 데이터를 모두 살폈다. 충분한 데이터량·개인정보 컬럼·합성 가능한 컬럼 구성·기관의 개방 가능성을 함께 고려해 후보군을 마련했다.
3. **실적 적합성과 이후 과정을 설명해 기관의 동의를 받았다.** 후보별로 지표 실적이 될 수 있는 이유, 합성데이터 생성 방법, 안전성·유용성 검증과 결과보고서 등 후속 활동·산출물을 설명했다. 기관 담당자의 동의 후 합성할 원본 데이터를 전달받았다.
4. **원본 컬럼을 검토해 처리 방안을 결정했다.** 제외할 컬럼인지, 어떤 정제가 필요한지, 다른 컬럼과 관계가 있어 합성 시 주의해야 하는지를 검토했다. 원본 컬럼명·개별 레코드나 특정 정제 규칙을 공개 문안에 추가하지 않는다.
5. **Python 오픈소스 라이브러리로 합성데이터를 생성·평가했다.** 컬럼 처리 방안을 결정한 뒤 생성·평가를 수행했다. 사용자는 평가 기준으로 개인정보보호위원회의 안내서를 따랐으며 관련 방법은 공개 코드를 참고하도록 설명했다. 코드의 모델 비교·평가 구현은 아래에서 구체화하고 기관별 채택 모델·설정·점수는 추정하지 않는다.
6. **평가 결과를 관계자 검증과 보고서로 연결했다.** 여러 관련자와 안전성·유용성 검증을 진행하고 수행팀이 결과보고서를 작성했다. 검증 참여자의 직책·수·외부 전문가 여부와 데이터별 정량 점수는 제시되지 않았다.
7. **기관 확인·공식화 후 제출·등록으로 이어갔다.** 기관은 결과보고서를 확인하고 결재 문서로 공식화했다. 수행팀이 산출물을 정리하고 기관 담당자가 평가자료를 제출하고 포털에 등록했다. 본인의 실무·기관 설명·검증 참여와 팀·기관의 후속 역할을 구분한다.
8. **이후 다른 기관 업무를 팀원에게 넘겼다.** S7!B2의 후속 분담이다. 한국산업기술진흥원의 제출·등록은 이번 답변에 따라 기관 담당자의 수행으로 기록하고, 다른 기관을 본인이 직접 수행·총괄한 것으로 확대하지 않는다.

코드를 실행하거나 원본 개인정보·비공개 데이터를 읽지 않았다. 현재 라이브러리 호환성, 실제 생성 결과, 안전성·유용성 점수, 처리시간·시간 절감은 재현하지 않았다. 공개 코드의 정적 열람을 기관의 안전성·유용성 검증 결과서 확인으로 대체하지 않는다.

## 기관 실무자와의 소통·설명·조율

- 직접 소통한 대상: 한국산업기술진흥원의 기관 담당자. 검증 단계에서는 여러 관련자와 함께 안전성·유용성을 검토했다. 데이터 보유 부서와의 별도 직접 연락·참여자 직책은 추정하지 않는다.
- 기관에 제시한 내용: 후보가 지표의 실적이 될 수 있는 이유, 합성데이터를 생성하는 방법, 이후 검증 과정과 안전성·유용성 검증 결과보고서 등의 산출물. 기술적인 생성만 설명한 것이 아니라 기관이 해야 할 후속 과정까지 제시했다.
- 합의와 실무 조치: 담당자가 후보와 수행 과정에 동의한 후 원본을 받아 컬럼 제외·정제·관계성을 검토하고 생성·평가했다. 코드 평가 결과는 관계자 검증과 보고서 작성으로 이어졌다.
- 후속 역할 분담: 수행팀이 결과보고서 작성·산출물 정리를 맡았다. 기관은 결과를 확인하고 결재 문서로 공식화한 뒤 담당자가 제출·포털 등록을 수행했다. 기관의 결재 권한·최종 등록을 본인의 직접 수행으로 쓰지 않는다.
- 책임 범위의 해석: 2026년 맡은 지표를 독립적으로 수행했다는 공통 설명은 본인의 실무 추진 책임으로 읽는다. SY의 보고서 작성은 수행팀, 최종 제출·포털 등록은 기관 담당자라는 이번 구체적인 분담을 우선한다. 자료에 없는 갈등·지연·방문 사례를 추가하지 않는다.
