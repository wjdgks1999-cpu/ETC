# 담당 업무: 공공데이터 활용사례집 제작

[공감데이터 전체 안내](../README.md) · [평가제도와 업무 연결](../evaluation/indicators-2026.md)

상태: 작성 완료·사용자 문안 확인 (2026.11.04). 보완 답변 3개와 Excel SU 재대조를 반영한 문안에 사용자가 동의하고 다음 작업을 문의해 완료로 정리했다. 추가 질문은 없다. 과기정통부 2025.11~2026.01 작업과 본인 중심 1차 집필·상사 중심 편집·공동 검토·외부 디자인 분담을 유지한다. 국토부는 2026.10 작업·1차 원고 전달 후 기관 최종 확인 대기로 진행 중이며, 이력 문서의 작성 완료와 구분한다.

## 기본 정보

- 업무·담당 지표명: 기관 공공데이터 활용사례집 제작(CB). 별도의 평가지표 번호·평가 등급은 해당 없음이다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 수행한 업무다.
- 사업연도와 실제 수행 기간: Excel의 과기정통부 2025년 사업은 2025년 11월~2026년 1월에 작업했다. 국토부 2026년 사업은 2026년 10월에 작업했고 2026.11.04 현재 기관 최종 확인 대기로 진행 중이다. 기관·사업연도와 실제 작업 기간을 구분한다.
- 적용 기관·범위: 과학기술정보통신부·국토교통부의 두 기관·연도·업무 조합. 두 권의 납품 완료나 수록 사례 전체의 단독 집필을 뜻하지 않는다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 `GG-2025-09-CB`, `GG-2026-14-CB`를 유지한다. 수요조사 결과 인용은 기존 `GG-2025-09-SU`와 연결한다.
- 사용 자료와 확인 기준: Excel S0 `참여사업 목록!A13:K13`·`A19:K19`, S2 `대국민 공공데이터 활용 수요조사!B2`·`D10:H10`, 과기정통부 사례집 B1, 기존 U1과 이번 CB 보완 답변 3개. CB 별도 상세 시트는 없다.

## 핵심 기여

- 사례 발굴·기관 확인: 과기정통부 제시 후보·산하기관 제출 사례·뉴스와 자료 탐색을 모아 후보군을 구성하고, 과기정통부 담당자의 검토로 최종 수록 대상을 선정했다. 국토부는 2026년 공공데이터포털 등록 활용사례를 후보로 삼고 데이터 분석 경진대회 수상사례를 모두 수록하는 범위로 기관 확인을 받았다.
- 자료 확보·기관 소통: 과기정통부와 산하기관에 사례의 구체 내용이 담긴 문서·성과 자료를 요청했다. 산하기관과 다수의 협조 요청 전화를 주고받으며 집필에 필요한 내용을 확보했다.
- 본인 중심의 1차 집필: 수집·선정한 사례로 1차 완성본을 작성했다. 본인은 1차 집필을 많이 맡았고 개방·활용 현황도 직접 정리했다. 기존 2025년 대국민 수요조사 결과를 인용해 조사 내용을 사례집에 연결했다.
- 협업 분담: 편집은 상사가 많이 맡았고 검토는 함께 진행했다. 디자인은 다른 기업에 맡겼다. 본인의 집필 기여와 상사·외부 기업의 역할을 함께 기록한다.
- 결과·진행 상태: 두 기관 모두 선정 사례를 바탕으로 1차 완성본을 작성했으며 국토부에는 이를 전달했다. 국토부의 최종 완료 여부는 기관 확인 전이다. 과기정통부는 위 기간의 작업과 기존 B1 파일을 근거로 설명하며 별도의 공식 검수·납품일은 특정하지 않는다.

## 문제와 반복 수행한 업무

### 기관별 사례 발굴·자료 확보·선정

| 단계 | 과학기술정보통신부 | 국토교통부 |
| --- | --- | --- |
| 수록 범위 | 공공데이터 민간활용, 데이터 분석, AI 도입·활용 사례 | 공공데이터 민간활용 사례와 국토부 데이터 분석 경진대회 수상사례 |
| 후보 발굴 | 부처가 제시한 후보, 산하기관이 제출한 사례, 수행팀의 뉴스·자료 탐색을 모아 후보군 구성 | 공공데이터포털에 2026년 등록된 국토부 공공데이터 활용사례를 후보로 선정. 경진대회는 수상사례 전부 수록 |
| 구체 자료 확보 | 과기정통부·산하기관에 구체적인 내용이 담긴 문서와 성과 요청. 산하기관과 협조 요청 전화 왕래 | 확인된 후보·수상사례를 바탕으로 작성. 과기정통부의 전화·문서 요청 방식을 국토부에도 동일하게 적용했다고 추가하지 않음 |
| 기관 확인 | 수집한 후보군을 과기정통부 담당자에게 검토받아 최종 선정 | 정한 후보군을 기관에서 확인받음 |
| 원고 작성·전달 | 선정 사례를 기반으로 1차 완성본 작성 | 확인된 후보·수상사례로 1차 완성본 작성·기관 전달. 현재 최종 확인 대기 |

부처·산하기관의 제출만 기다리지 않고 뉴스·자료 탐색으로 후보를 보완한 점, 사례를 설명할 문서·성과를 기관에 요청하고 선정 검토로 연결한 점을 발굴·소통 기여로 설명한다. 과기정통부와 국토부의 실제 경로 차이를 유지한다.

### 집필·현황 정리와 역할 분담

- 본인은 1차 집필을 많이 맡았고 개방·활용 현황을 정리했다. 부록·각 절의 집필량이나 전체 원고의 단독 작성 비율은 특정하지 않는다.
- 수요조사 결과는 2025년에 수행한 대국민 공공데이터 개방수요조사 결과를 인용했다는 사용자 답변을 반영한다. Excel S0!E13 O와 S2!D10:H10에서 본인의 과기정통부 2025년 SU 담당을 재확인했다. S2!B2의 공통 역할은 설문지 작성·객관식 및 주관식 분석·결과보고서 작성이다.
- 이는 [수요조사 업무 기록](public-data-demand-survey.md)의 `GG-2025-09-SU` 결과를 사례집에서 인용한 연결이다. CB를 위해 별도 설문을 추가 수행한 건수로 합산하거나 조사 전체 표본·설정·보고서 내용을 이번에 재검증한 것으로 쓰지 않는다.
- 편집은 상사가 많이 맡고 검토는 공동으로 진행했다. 디자인은 외부 기업에 맡겼다. ‘집필·편집 참여’라는 기존 설명을 유지하되 본인의 중심 역할은 자료 확보·현황 정리·1차 집필·공동 검토로 구체화한다.
- 사용한 문서·편집 도구나 코드·자동화는 별도 확인되지 않았다. 이를 추가 필수 질문으로 남기거나 관련 없는 ETC 코드를 연결하지 않는다.

### 산출물에서 확인한 설명 구조

B1은 공공데이터 소개, 개방·활용 현황과 수요조사 결과, 과학기술·ICT 분야 AI·데이터 활용 사례, 부록으로 구성된다. 대표 사례에는 제작사·사례유형·활용데이터 및 제공기관, 주요 서비스 내용·활용데이터·주요 성과를 구분한 형식이 있다. 이는 문서 구성의 근거이며 수록 기관의 기술·서비스를 본인이 개발했다는 근거가 아니다.

## 기관 실무자와의 소통·설명·조율

- 과기정통부: 부처와 산하기관에 구체적인 사례 문서·성과를 요청하고 산하기관과 여러 협조 요청 전화를 주고받았다. 후보군은 과기정통부 담당자의 검토를 받아 최종 선정했다.
- 국토부: 포털 등록 사례와 경진대회 수상사례로 수록 범위를 정하고 후보군을 기관에서 확인받았다. 이후 1차 완성본을 전달했다. 후보 선정 확인과 최종 원고의 완료 확인은 구분한다.
- 사내·외 분담: 본인 중심 1차 집필·현황 정리, 상사 중심 편집, 공동 검토, 외부 기업 디자인이다. 2026년 담당 업무를 독립적으로 추진했다는 회사 경력의 설명을 전체 집필·편집·디자인의 단독 수행으로 확대하지 않는다.
- 자료에 없는 기관별 회신 지연·갈등·방문·협의 횟수·완료율은 추가하지 않는다. 반복 연락과 자료 확보·기관 선정 확인·원고 작성이라는 실제 행동으로 경험을 설명한다.

B1 표지·파일명은 2025년이고 본문에는 2026년 1월 정보가 있다. 이번 답변으로 실제 작업이 해를 넘어 2026년 1월까지 이어졌음을 확인했다. 수록 사례의 서비스 개시일이나 통계 기준일을 개인의 정확한 작업일로 대신하지 않는다.

후보 발굴 → 구체 자료 확보 → 기관 선정 확인 → 1차 집필·상사 편집·공동 검토·외부 디자인의 분담으로 작업을 설명한다. 세부 마감 관리 도구·날짜·지연 대응을 추가로 요구하지 않는다. 국토부는 기관의 최종 확인이 오면 진행 상태를 갱신할 수 있으며 현재 완료 성과로 선반영하지 않는다.

B1 97쪽은 사례집 산출물의 분량이다. 개인 집필 쪽수·개발한 서비스 수가 아니다. 수록 기관·기업의 매출·이용량·개발·AI 성능·시간 절감이나 SU의 평가 등급을 CB의 개인 성과·평가로 가져오지 않는다.

## 채용 담당자용 요약

- 한 문장: 기관별 수록 범위에 맞춰 활용사례를 발굴하고 기관과 자료 확보·선정을 조율했으며, 현황 정리와 1차 집필을 중심으로 상사·외부 기업과 협업해 사례집을 제작했다.
- 짧은 서술: 과기정통부에서는 부처 후보·산하기관 제출·뉴스와 자료 탐색을 모아 사례 후보군을 구성했다. 산하기관과 협조 요청 전화를 주고받으며 구체 문서·성과를 확보하고 부처 담당자의 검토로 수록 대상을 선정했다. 개방·활용 현황을 정리하고 본인이 담당한 2025년 수요조사 결과를 인용해 1차 원고 작성에 기여했다. 국토부에서는 2026년 포털 등록 활용사례와 데이터 분석 경진대회 수상사례를 기관 확인 후 원고로 정리해 전달했다. 본인은 1차 집필을 많이 맡고 상사는 편집을 많이 맡았으며 검토는 함께, 디자인은 외부 기업이 담당했다. 국토부는 현재 기관의 최종 완료 확인을 기다리고 있다.
- 드러나는 역량: 기관별 후보 발굴, 협조 요청·자료 확보·선정 확인의 소통, 개방·활용 현황 정리와 기존 조사 결과 활용, 기술·활용 내용을 설명하는 원고 작성, 역할을 나눈 제작·공동 검토.
