# 담당 업무: 데이터 값 관리

[공감데이터 전체 안내](../README.md) · [평가제도와 업무 연결](../evaluation/indicators-2026.md)

상태: 작성 완료·사용자 확인 (2026.11.04). 원본 대조·보완 질문 3개 답변 반영 후 사용자가 DQ 완료 정리와 CB 진행을 요청했다. DB 연결·대상 제외·프로파일링·컬럼별 기준 설정·진단·보고서 작성과 기관 동의 후 업무규칙 진단을 정리했다. 상사 검토·실제 오류 수정 미수행·사업별 착수에 따라 달라지는 시기를 유지하며 추가 질문은 없다. 진단도구 결과산출물 비공개와 이번 실행 미재현도 유지한다.

## 기본 정보

- 업무·담당 지표명: 데이터 값 관리(DQ). Excel S4!A2는 `2-2 데이터 값 관리` 아래 `2-2-1 데이터 품질진단`·`2-2-2 데이터 오류율`로 설명한다. 이는 사용자 Excel의 지표 설명이며 2024년 공식 편람의 명칭·배점·요건을 별도로 검증한 것은 아니다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 수행한 업무다.
- 수행 기간·해당 연도: 2024년 사업. 실제 작업 시기는 사업별 착수 시점에 따라 달라 공통 월을 특정하기 어렵다는 사용자 답변을 반영한다. 개인의 정확한 날짜·고정 소요기간을 정하거나 추가 질문으로 요구하지 않는다. 2025·2026년은 제공된 Excel에 DQ 담당 표시가 없다.
- 적용 기관·지표 범위: 한국탄소산업진흥원·한국소비자원의 두 기관·연도·업무 조합. 사업명에 품질이 포함된 다른 기관의 업무를 추가하지 않는다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 `GG-2024-03-DQ`, `GG-2024-19-DQ`를 유지한다. 한국탄소산업진흥원 S0 4행·30행은 같은 사업의 AN·DQ 분리 행이며 기관·연도 묶음은 하나다.
- 사용 자료와 확인 기준: Excel S0 `참여사업 목록!A4:K4`, `A30:K31` 및 S4 `데이터 값 관리!A1:H3`, 기존 회사 역할·공개 범위와 사용자 DQ 보완 답변 3개(2026.11.04). 경력증명서 C1의 기존 사업 연결은 공통 기관 이력표를 따른다.

## 핵심 기여

- 직접 수행한 실무: 기관 DB를 진단도구가 설치된 컴퓨터에 연결하고 제외할 테이블을 선정했다. 대상 테이블을 프로파일링한 뒤 컬럼명·실제 값을 검토해 진단기준을 설정하고 비정형 텍스트 컬럼을 제외해 오류율을 산출했다. 프로파일링은 WDQ의 기능을 활용한 것이며 도구를 직접 개발한 경험으로 확대하지 않는다.
- 업무규칙 선정·기관 확인: 데이터를 보며 정의하기 적절한 업무규칙 후보를 정리해 기관에 제시했다. 기관이 동의한 규칙을 정의하고 해당 컬럼이 규칙을 따르는지 추가 진단해 결과를 산출했다.
- 직접 작성한 산출물: 진단 결과에 기반해 품질진단 결과보고서·개선계획서를 작성하고 기관에 전달했다. 두 기관의 전달 결과는 S4!G2:G3에 기재되어 있다.
- 역할 분담과 검토: 본인이 진단·업무규칙·산출물 작성을 맡고 상사 검토를 거쳤다. 2024년 기관 소통은 대부분 상사가 담당했다는 기존 분담을 유지한다. 본인은 실제 데이터 오류 수정을 수행하지 않았다.
- 과업 마무리: 두 기관의 진단율 100%·보고서 전달·해당 지표 만점은 Excel 기재값이다. 진단과 결과보고서·개선계획서 작성·전달을 본인의 수행 범위로 설명한다. 공통 작업 월·고정 기간이나 구체적인 마감 관리 일화는 만들지 않는다.

## 문제와 반복 수행한 업무

### 기관의 요구와 해결할 문제

기관이 운영하는 정보시스템 DB에서 진단할 대상과 기준을 정하고, 진단 결과와 개선계획을 기관이 검토할 보고서로 정리하는 업무다. 사용자 수행 설명에 따르면 도구를 실행하기에 앞서 제외할 테이블과 컬럼을 구분하고, 남은 컬럼의 이름·실제 값을 검토해 적절한 진단기준을 설정했다.

Excel S4!A2는 법령·지침·업무규정 등에 따른 검증·진단기준 정의를 지표의 맥락으로 설명한다. 실제 업무규칙은 데이터를 살펴 후보를 정리하고 기관의 동의를 받아 정의·진단한 과정으로 기록한다. 법령 검토·기관 전체 품질관리·운영 DB의 오류 수정을 모두 본인이 수행한 것으로 확대하지 않는다.

### 실제 진단 흐름과 산출물

다음은 S4!B2와 사용자 수행 과정 답변(2026.11.04)을 연결한 공통 업무 흐름이다. 기관별 테이블·컬럼·규칙 원문과 수량은 공개하거나 추정하지 않는다.

| 단계 | 본인이 수행한 일 | 판단·범위와 산출물 |
| --- | --- | --- |
| 1. DB 연결 | 기관 DB를 WDQ·SDQ 등 기관이 정한 진단도구가 설치된 컴퓨터에 연결 | 연결 과정에서 방화벽 문제가 발생했지만 해결은 본인·수행팀의 담당 범위가 아니었음. 해결 주체·대응 일화는 추가하지 않음 |
| 2. 제외 대상 테이블 선정 | 진단 대상 DB에서 제외할 테이블을 정리 | 백업·임시·시스템관리용·코드 테이블 등은 제외 가능한 대상으로 설명함. 모든 기관에서 이 유형을 일괄 제외했다는 뜻은 아님 |
| 3. 대상 테이블 프로파일링 | 진단 대상 테이블을 WDQ의 프로파일링 기능으로 살펴봄 | 도구의 기능을 활용해 후속 컬럼별 기준 설정으로 연결 |
| 4. 컬럼별 진단기준 설정 | 컬럼명과 실제 값을 보고 날짜·수량·규칙 등 적절한 품질진단 기준을 지정 | 비정형 텍스트로 구성된 컬럼은 진단에서 제외. 예시 기준을 모든 컬럼에 동일 적용했다고 쓰지 않음 |
| 5. 진단·오류율 산출 | 제외 대상을 정리한 뒤 진단 대상 컬럼에 기준을 설정해 품질진단 수행 | 진단 오류율 산출. 실제 오류율 값·진단 규모는 현재 미확인 |
| 6. 결과보고서·개선계획 작성 | 진단 결과에 따라 품질진단 결과보고서·개선계획안 작성 | 업무는 상사 검토를 거쳤고 두 기관에 보고서·개선계획서 전달은 S4!G2:G3 기재값. 본인은 실제 오류 수정을 수행하지 않음 |

### 기관 확인을 거친 업무규칙 진단

컬럼별 품질진단에 더해 데이터를 검토하면서 업무규칙으로 정의하기 적절한 항목들을 정리해 기관에 제시했다. 기관이 동의하면 해당 업무규칙을 정의하고 관련 컬럼에 진단을 수행해 규칙 준수 여부와 결과를 산출했다. **데이터 검토 → 규칙 후보 제시 → 기관 동의 → 규칙 정의·해당 컬럼 진단**의 과정을 본인의 기여로 설명한다.

기관 동의는 규칙 적용에 대한 확인이다. 업무는 상사 검토를 거쳤으며 2024년 기관 소통은 대부분 상사가 담당했다는 기존 설명과 함께 읽는다. 규칙별 전달 경로나 상사의 세부 검토 항목을 추가로 특정하지 않는다.

- 도구·코드: 사용자는 WDQ나 SDQ처럼 기관이 정한 품질진단도구에 DB를 연결하는 업무이며 별도 보조 코드는 없다고 설명했다. Excel에 명시된 도구는 WDQ다. 이 답변을 두 기관 모두에서 WDQ와 SDQ를 함께 사용했다는 뜻으로 확대하지 않는다.
- 주요 판단: 모든 테이블·컬럼을 같은 방식으로 진단하지 않고 제외 대상과 비정형 텍스트 컬럼을 구분했다. 남은 컬럼의 이름·값에 맞는 기준을 설정하고 업무규칙은 기관 동의 후 적용했다. 다른 업무의 Python·LangChain·ETC 코드를 DQ에 연결하지 않는다.
- 실제 개선과의 구분: 본인은 실제 데이터 오류 수정을 수행하지 않았다 (사용자 확인, 2026.11.04). 진단과 개선계획서 작성·전달까지의 기여로 기록하며 기관의 후속 수정 여부·개선 완료를 본인 성과로 쓰지 않는다.

## 기관 실무자와의 소통·설명·조율

- 확인된 연도별 분담: 2024년 기관 커뮤니케이션은 대부분 상사가 담당했고 본인은 산출물 작성에 주로 집중했다. DQ 업무도 상사 검토를 거쳤다.
- 확인된 기관과의 연결: 데이터에 적합한 업무규칙 후보를 정리해 기관에 제시하고, 동의받은 규칙을 정의·진단했다. 결과보고서·개선계획서를 작성해 두 기관에 전달한 결과와 연결한다. 기관별 전달 경로·최종 제출 주체는 자료 이상으로 특정하지 않는다.
- 수행 범위: 본인은 실제 오류 수정을 수행하지 않았다. 현재 추가 질문은 없으며 구체적인 내부 대화·DB 접속 정보·규칙 원문·화면이나 기관의 후속 수정 내역을 요구하지 않는다.
- 확인된 요구·제약과 합의: 기관이 정한 진단도구를 사용하고 업무규칙은 기관 동의를 거쳐 적용했다. DB 연결 과정의 방화벽 해결은 본인·수행팀 범위에서 제외한다. 개별 갈등·지연 대응이나 다른 업무의 설득·방문 사례를 가져오지 않는다.

## 일정 관리와 과업 완수

- 사업연도와 실제 시기: 두 사례 모두 2024년이다. 작업 시기는 사업별 착수에 따라 달라 공통 시기를 특정하기 어렵다는 답변을 받았다. 정확한 날짜·공통 월·고정 소요기간을 추가로 요구하지 않으며 경력증명서 참여기간으로 대신하지 않는다.
- 확인된 과업 마무리: 두 기관 모두 진단율 100%, 결과보고서·개선계획서 전달 및 해당 지표 만점이 Excel에 기재되어 있다.
- 확인된 검토: 업무는 상사 검토를 거쳤다. 구체적인 검토 횟수·항목·수정 지시나 일정 관리 도구·마감 대응 일화는 답변에 없으므로 추가하지 않는다.
- 성과의 범위: 진단과 보고서·개선계획서 작성·전달로 과업을 설명한다. 실제 오류 수정은 본인이 수행하지 않았으며 진단율을 오류 개선 완료율로 바꾸지 않는다. 기관별 정확한 기한·완료일·완료율은 별도 확정하지 않고 추가 질문으로 남기지 않는다.
- 연도별 기준: 이번 DQ 작성에서 2026년 편람의 품질진단 관련 절을 별도로 대조하지 않았다. 2026년 인정기간·요건·배점을 2024년 수행 사실로 사용하지 않는다.

## 채용 담당자용 요약

- 한 문장: 기관 DB의 제외 대상을 정리하고 프로파일링·컬럼별 기준 설정으로 품질을 진단했으며, 기관이 동의한 업무규칙을 적용하고 결과보고서·개선계획서를 작성했다.
- 짧은 서술: 2024년 한국탄소산업진흥원·한국소비자원의 DB 품질진단에서 기관이 정한 진단도구를 사용했다. 제외할 테이블을 선정하고 WDQ로 대상 테이블을 프로파일링한 뒤 컬럼명·실제 값을 검토해 진단기준을 설정했다. 비정형 텍스트 컬럼은 제외하고 진단 오류율을 산출해 결과보고서·개선계획서를 작성했다. 데이터에서 업무규칙 후보를 정리해 기관에 제시하고 동의받은 규칙을 정의·적용해 해당 컬럼의 준수 여부도 진단했다. 업무는 상사 검토를 거쳤으며 당시 기관 소통은 대부분 상사가 담당했다. Excel에는 두 기관 각각 진단율 100%, 보고서 전달과 해당 지표 만점이 기재되어 있다. 본인의 수행 범위는 진단과 보고서·개선계획서 작성·전달이며 실제 오류 수정은 수행하지 않았다.
- 드러나는 역량: 진단 대상 구분, 프로파일링 결과·컬럼명·값을 고려한 기준 설정, 기관 확인을 거친 업무규칙 정의·검증, 상사 검토를 거친 진단 결과 문서화와 개선계획 작성.
