# 담당 업무: 공공데이터·데이터기반행정 컨설팅 제안서 작성

[공감데이터 전체 안내](../README.md) · [평가제도와 업무 연결](../evaluation/indicators-2026.md)

상태: 확인된 범위로 작성 완료·사용자 확인 (2026.11.04). Excel S0·S1 대조와 추가자료 없음 답변을 반영한 문안에 사용자가 동의하고 다음 업무 진행을 요청했다. 세부 작성 방법·협업·일정·발표 분담의 질문 2개는 답변을 받지 않았으며 미확인으로 유지한다. 이를 추가 완료 조건으로 요구하지 않고 회사 수주 결과와 확인된 개인 기여만 기록한다.

## 기본 정보

- 업무·담당 지표명: 제안서 작성(PR). 공공데이터 제공·데이터기반행정 평가 대응 컨설팅 사업의 제안서·발표자료 준비 업무다. PR 자체에 별도의 행정안전부 평가지표 번호·평가 등급은 해당 없음이다.
- 관련 회사 경력: [공감데이터 경력 개요](../employment.md). 데이터사업부 선임연구원으로 담당한 업무다.
- 수행 기간·해당 연도: 2025·2026년 사업. 2025년 4개·2026년 7개, 총 11개 기관·연도·업무 조합이다. 사업연도를 개인의 정확한 제안서 작성 기간으로 대체하지 않는다. 2024년은 제공된 Excel에 PR 담당 표시가 없다.
- 적용 기관·지표 범위: 아래 11개 PR 조합. 제안서 전체를 본인 혼자 작성했거나 기관 전체 사업을 총괄했다는 의미가 아니다.
- 연결할 기관 이력표·사례 ID: [공통 기관 이력표](../institutions-by-year.md)의 기존 PR ID 11개. 번호를 재배정하지 않는다.
- 사용 자료와 확인 기준: Excel S0 `참여사업 목록!D열`의 담당 표시와 해당 기관·사업명, S1 `제안서 작업!A1:H12`, 기존 회사 역할·공개 범위. 실제 RFP 원문·제안서·발표자료는 이번 자료에 없으며 해당 문서를 읽거나 내용·분량을 검증한 것으로 쓰지 않는다.

## 핵심 기여

- 직접 책임진 산출물: 본인이 맡은 지표의 제안서를 작성하고 기관에 맞춘 발표자료를 마련했다 (S1!B2). 최종 제안서의 전체 집필·편집 책임이나 실제 발표를 맡았다고 확대하지 않는다.
- 기관 현황 자료 가공: 기관 공공데이터 현황 등의 데이터를 수집·정제하고 시각화했다 (S1!B2). 구체적인 출처·도구·시각화 방법·기관별 제안 반영 방식은 미확인으로 두고 추정하지 않는다.
- 제안 목적과 연결: RFP 요구사항을 분석해 부합하는 제안서·발표자료를 준비하는 업무라는 S1!A2의 설명과 본인의 담당 파트를 연결한다. 개별 요구사항·평가 항목과 직접 작성한 내용은 자료 없이 만들지 않는다.
- 협업·일정: 본인 파트의 작성·현황 자료·발표자료 준비는 확인했다. 동료·상사의 검토·취합·최종 제출·발표 분담과 마감 대응은 별도 답변이 없어 미확인이다. 사업 수행 단계의 기관 소통 경험을 제안 단계에 그대로 옮기지 않는다.
- 결과: Excel의 11개 조합 모두 ‘사업 수주 성공’으로 기재되어 있다. 이는 회사의 선정·수주 결과이며 본인의 담당 파트 작성·자료 준비 기여와 구분한다. 개인 단독 수주, 전체 입찰 승률·수주액으로 환산하지 않는다.

## 문제와 반복 수행한 업무

### 사업 제안에서 해결할 문제

기관이 발주한 공공데이터 제공·데이터기반행정 평가 대응 컨설팅의 요구에 맞춰 수행 방안을 설명하는 제안서와 발표자료를 준비하는 업무다. Excel S1!A2는 RFP 요구사항 분석과 이에 부합하는 문서 작성을 공통 업무로 설명한다. 본인의 역할은 담당 지표의 제안 파트와 기관 현황 자료·맞춤 발표자료 작성으로 기재되어 있다.

평가 대응 사업을 제안하는 단계와 수주 후 해당 지표를 실제 수행하는 단계는 구분한다. 제안 참여 기관에서 본인이 모든 후속 지표를 수행했다고 가정하지 않으며, 다른 업무의 활동·평가 결과를 PR의 산출물이나 성과로 합산하지 않는다.

### 기존 자료로 확인한 업무 구성

1. **RFP 요구에 맞는 제안을 준비한다.** S1!A2의 업무 목적은 요구사항 분석과 제안서·발표자료 작성이다. 개별 RFP의 조항·배점·작성 양식을 이번에 확인한 것은 아니다.
2. **담당 지표의 제안서를 작성한다.** S1!B2는 ‘내가 맡은 지표들’에 대한 작성으로 범위를 한정한다. 기관·연도별 작성 지표, 페이지 수·비중, 수행 방안·일정 설계의 구체적인 방식은 아직 제시되지 않았다.
3. **기관 공공데이터 현황 등을 수집·정제·시각화한다.** 기관 현황을 파악하고 자료로 정리한 기여다. 특정 데이터 출처·지표·전후 변화, 크롤링·자동화·코드 적용은 답변 없이 확정하지 않는다.
4. **기관에 맞는 발표자료를 작성한다.** 준비된 현황 자료와 제안 내용의 구체적인 연결 방식은 별도 설명이 없어 미확인으로 둔다. 발표자료를 만들었다는 사실을 본인이 제안 발표·질의응답을 수행한 것으로 바꾸지 않는다.
5. **회사 선정 결과와 본인 기여를 연결한다.** S1!G2:G12에 기재된 수주 결과를 담당 지표의 제안서·자료 작성과 함께 기록한다. 회사의 최종 제출·발표·협상·계약 체결 주체는 별도 분담 확인 전이다.

### 기술·도구와 주요 판단

현황 데이터의 수집·정제·시각화는 Excel에 기재된 실제 업무다. 사용 언어·라이브러리·문서 도구·시각화 도구와 자동화 여부는 현재 자료에 없다. 따라서 Python·Excel·PowerPoint 등 특정 제품을 사용했다고 새로 적거나 ETC의 다른 업무 코드를 임의로 연결하지 않는다.

기관별 맞춤 제안 과정에서 어떤 현황을 중요하게 보았고 수집·시각화 결과를 어떻게 수행 방법·일정으로 연결했는지는 별도 답변이 없어 미확인이다. 현재 문안의 승인과 다음 업무 진행 요청에 따라 추가 질문으로 남기지 않는다. 모든 기관에 동일한 데이터·도구·절차를 적용했다고 추정하지 않는다.

## 기관 실무자와의 소통·설명·조율

- 확인된 개인 역할은 문서·현황 자료·발표자료 작성이다. PR 단계에서 본인이 발주기관 실무자와 직접 협의했는지는 별도 확인되지 않았다.
- 사내 협업 대상·역할 분담, 원고 검토·피드백 반영, 취합·최종 제출·실제 발표 주체는 미확인으로 남긴다. 자료에 없는 소통·완수 사례로 채우지 않는다.
- 이미 확인한 2025년 대부분 지표 전반 수행·2026년 담당 지표 독립 수행이라는 회사 경력의 변화는 유지하되, 제안 단계의 기관 접촉·협상·최종 결재 권한을 의미하는 것으로 확대하지 않는다.
- 현재 자료에 없는 갈등·설득·기관 방문이나 SH·SY·AN의 수행 일화를 제안 단계의 사례로 가져오지 않는다.

## 일정 관리와 과업 완수

- 주요 기한: 기관별 입찰·제안서 제출·발표 마감의 정확한 날짜는 현재 자료에 없다. 행정안전부 평가지표의 실적 인정기간·제출 기한을 제안서 작성 기한으로 사용하지 않는다.
- 본인 수행: 담당 지표 제안서, 기관 현황 자료와 발표자료 작성이 S1!B2에 기재되어 있다. 작성·검토·수정·최종 전달의 세부 일정은 미확인으로 유지한다.
- 완료 결과: 11개 조합에 회사의 사업 수주 성공이 기재되어 있다. 이를 본인이 최종 제출·발표를 직접 수행했다거나 모든 입찰에서 선정되었다는 근거로 쓰지 않는다.
- 자료 요청·우선순위·마감 대응: 세부 방법은 미확인이다. 정확한 날짜·기관별 특별한 지연 사례·추가 완료율을 추가로 요구하거나 만들어 넣지 않는다.

- 수치 외 산출물: 담당 지표 제안 원고, 기관 현황의 수집·정제·시각화 자료, 기관에 맞춘 발표자료. 원본 파일·화면은 제공하지 않는다.

- 근거 구분: 제안 목적·공통 역할·기관별 결과는 사용자 Excel, 조직·역할 변화·공개 범위는 기존 확정 답변이다. 수주 결과를 별도 계약서·공식 선정 결과서로 독립 검증하거나 현황 처리 코드를 실행한 것은 아니다.

## 채용 담당자용 요약

- 한 문장: 공공데이터·데이터기반행정 컨설팅 사업 제안에서 담당 지표의 제안서를 작성하고, 기관 현황 데이터의 수집·정제·시각화와 맞춤 발표자료 준비로 회사의 사업 제안에 기여했다.
- 짧은 서술: 기관이 발주한 컨설팅의 RFP 요구에 부합하는 제안을 준비하면서 본인이 맡은 지표의 제안서를 작성했다. 기관 공공데이터 현황 등을 수집·정제·시각화하고 대상 기관에 맞는 발표자료를 만들었다. Excel에는 2025년 4개·2026년 7개 PR 조합의 사업 수주 성공이 기재되어 있다. 회사의 선정 결과와 본인의 담당 파트·자료 작성 기여를 구분한다. 구체적인 작성 도구·발표·마감 관리 사례는 미확인으로 두고 요약에 추가하지 않는다.
- 드러나는 역량: 담당 지표의 문서 작성, 기관 현황 자료 가공·시각화, 대상 기관에 맞춘 발표자료 준비.
