## 자료와 집계 기준

- 기준 자료: 사용자가 한국소비자원 항목을 추가한 `Gonggam_career.xlsx`의 8개 시트. 원본은 수정하지 않았다.
- 읽고 확인한 날짜: 2026.11.04. 한국과학창의재단은 분석·정책활용 X / 공유데이터 O, 한국소비자원은 2024년 데이터 값 관리로 확인했다.
- 재직 정보: 2024.05.07 입사, 2026.11.04 현재 공감데이터 데이터사업부 선임연구원으로 재직 중. 입사 때부터 현재까지 동일 부서·직책이다 (사용자 추가 확인, 2026.11.04).
- 연도는 Excel의 사업연도다. 증명서의 실제 참여 기간이 다음 해에 걸치더라도 임의로 사업연도를 바꾸지 않는다.
- 기본 단위는 **연도 × Excel 대표기관명 × 담당 업무**다. 업무별로 고유 사례 ID를 부여하고 동일 단위의 세부 대상은 하위 사례로 관리한다.
- 기관명 집계, 기관·연도 조합, 업무 조합, 분석·등록 실적 건수를 구분한다. 아래 숫자는 문서 정리 단위이며 프로젝트·계약 건수나 전체 고객기관 수로 사용하지 않는다.
- `농정원`은 `농림수산식품교육문화정보원`, `탄소산업진흥원`은 `한국탄소산업진흥원`으로 통일했다. 표기가 다른 연도별 부처명은 원문대로 유지하며 기관의 승계·통합 관계를 추정하지 않는다.
- 한국탄소산업진흥원의 S0 4행·30행은 같은 연도·기관·사업에 분석과 품질진단이 나뉘어 있어 기관·연도 목록에서 한 행으로 묶고 두 업무를 보존했다.
- 한국교육학술정보원은 Excel 대표기관 기준으로 한 번 집계한다. 경기·인천·강원 3개 교육청의 실제 실적은 하위 대상에 따로 기록하며 대표기관과 교육청을 합쳐 기관 수를 늘리지 않는다.
- Excel의 O/X는 해당 자료에서의 업무 담당 표시다. X를 기관 전체 사업의 미수행이나 회사 전체의 실적 없음으로 해석하지 않는다.
- 만점·우수·최우수 등은 **사용자 작성 Excel의 기재값**이다. 별도 공식 평가 결과서를 검증한 값으로 표시하지 않는다. 2026년의 제출·등록 완료 기재와 미공개 정성평가·미정 인정 결과를 구분한다.
- 개별 과업의 제출 기한·완료일·기한 준수는 자료에 없으면 확인 필요로 둔다. 경력증명서 참여기간의 끝을 과업 완료일·퇴사일로 대체하지 않는다.

## 연도별 집계

### 한국산업기술진흥원 사업명 분리 — 2026.11.16 사용자 확인

한국산업기술진흥원은 2024~2026년 각 연도에 공공데이터 제공·운영 사업과 데이터기반행정 사업이 별도로 발주됐다. Excel에서는 한 셀에 함께 적혀 있었으며, 사용자가 별도 사업으로 구분하도록 확인했다. 위 사업 목록에서는 각각 한 행으로 분리하고, 공공데이터 지표인 SU·PU·SY는 공공데이터 사업에, AN·SH는 데이터기반행정 사업에 연결했다. 해당 연도에 실제 수행 표시가 있는 업무만 배분했으며 새 업무 실적은 추가하지 않았다.

분리 후 표시용 사업 목록은 2024년 8행·2025년 11행·2026년 13행으로 총 32행이다. 이는 아래 원본 30행·기관 및 연도 29개 묶음과 집계 단위가 다르다. 고유 기관 수·기관 및 연도 수·업무 조합 69개는 변하지 않는다. 두 사업의 경력증명서 등록 여부를 각각 새로 확인한 것은 아니며 기존 C1의 기관·연도 대조 범위를 유지한다. Excel 원본은 수정하지 않았다.

- 개인 수행과 기관·팀 실적이 구분되어 있는지, 미공개·미정 평가와 측정 근거가 없는 수치의 한계가 유지되는지 검토한다. 이미 허용된 공개 범위를 반복 확인하지 않는다.
- 입사부터 현재까지 부서·직책이 동일하다는 점과 연도별 실질 책임 범위의 변화는 확인했다. 없는 납품일·제출 기한·기관별 도구 적용을 추가 필수 질문으로 두지 않으며 남은 작업은 이력표 문안 검토다.

기관 목록의 자료 차이·공개 범위 질문과 AN·SH·SY·SU의 보완 질문은 해결했다. PR은 사용자 요청에 따라 확인된 문안 범위로 완료했고 세부 질문 2개의 미답변 사항은 미확인으로 보존한다. SU도 U5·U6 반영 후 사용자 확인을 마쳐 완료했으며 현재 추가 질문은 없다. 해결된 항목이나 사용자가 현재 문안으로 다음 업무 진행을 요청한 항목, 추가 원본·화면·정확한 날짜를 다시 요구하지 않는다. DQ도 U7~U9로 보완 질문 3개의 답변을 모두 반영했으며 추가 질문은 없다. 상사 검토·오류 수정 미수행·시기 특정 어려움을 반영한 뒤 사용자 확인·요청에 따라 작성 완료로 정리했다 (2026.11.04). CB도 보완 질문 3개 답변과 SU 담당 재확인을 반영했으며 추가 질문은 없다. 사용자 문안 확인 후 CB 이력은 작성 완료이며 국토부 업무는 기관 최종 확인 대기로 진행 중이다.
