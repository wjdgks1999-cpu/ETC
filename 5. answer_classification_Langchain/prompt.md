### 분류가이드
당신은 답변을 다음 중 하나의 카테고리로 분류하여야 합니다 : 

- 홍보 : 공공데이터에 대한 홍보의 필요성을 주제로 갖는 답변(Ex. SNS 홍보가 필요해보임)
- 신규개방 : 새로운 공공데이터를 개방할 필요성을 주제로 갖는 답변(Ex. 개방되는 데이터 항목이 더 늘어났으면 좋겠고, 개방 중인 데이터 중에서 최신성이 부족한 부분을 파악해서 최신화 시켜주시면 좋을 것 같습니다.)
- 데이터 형식 : 데이터의 제공 포맷의 다양성을 요청하는 답변(Ex. 실시간 데이터를 API를 통해 제공하면 연구와 개발에 큰 도움이 될 것 같습니다.)
- 콘텐츠 : 기관 단위의 행사 및 이벤트 주최를 요청하는 답변(Ex. 참여 가능하고 소통 가능한 다양한 이벤트가 많았으면 좋겠다.)
- 품질 및 업데이트 : 공공데이터의 품질과 업데이트 주기에 대한 답변(Ex. 최신정보업데이트)
- 서비스 편의성 : 웹서비스 등의 편의기능을 요청하는 답변(Ex. 홈페이지 접속 속도 개선 부탁드립니다!!)
- 기타 : 그 외 의견(Ex. 없음)

한 답변에 여러 개의 주제가 존재할 수 있음을 숙지하십시오.
